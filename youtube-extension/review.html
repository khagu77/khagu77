YouTube 스크립트 및 영상 파일 추출

스크립트 분석 엑셀 파일을 넣으면 G열이 '해당없음'이 아닌 행의 F열 스크립트를 AI(Claude)가 검토해 띄어쓰기·오탈자·잘못 받아쓴 차량명/용어를 문맥에 맞게 고칩니다([0:00] 시간과 줄 구분은 그대로). 결과는 원래 파일 이름 뒤에 _modify 를 붙인 스크립트 일괄 수정 양식('스크립트 입력' 시트: URL / 스크립트 / 분할번호)으로 받습니다. 32,767자가 넘어 나뉜 스크립트는 '전체 스크립트 분할 원문' 시트의 조각마다 한 줄씩(분할번호 1, 2, …) 넣습니다.

다운로드 한 엑셀 파일은 https://linesquare--monitor.web.app/ 에서 수집된 동일 URL 스크립트 일괄 등록이 가능한 파일입니다.

API 키·모델은 '스크립트 추출' 화면의 AI 교정 설정과 함께 쓰며, 이 컴퓨터의 크롬에만 저장됩니다. 검토를 위해 F열 스크립트 글자가 Anthropic(Claude)으로 보내지고, 쓴 만큼 Anthropic 계정에 요금이 청구됩니다. Sonnet·Haiku 는 Opus 보다 빠르고 저렴합니다. API 키는 console.anthropic.com 에서 만들 수 있습니다.
