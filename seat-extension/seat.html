1. 동호회 게시물 찾기

차종별 양산 시점부터 끝 날짜까지, 동호회마다 검색어를 하나씩 검색해 2·3열 시트 조작 중 위험상황을 언급한 글을 찾습니다. 글이 많아 오래 걸리니(동호회·검색어 하나에 1~2분) 차종을 나눠 찾아도 됩니다. 찾은 글은 앞서 찾은 글에 더해집니다.
찾기차종시작일 (양산 시점)동호회
설정 (동호회 · 검색어 · 관련 단어 · 저장 위치)
차종동호회명영문 주소카페 번호 (찾을 때 자동으로 알아냄, 직접 넣어도 됨)
게시일이 '첫 로데이터에 담긴 게시일 시작' 이전이고 로데이터에도 없는 글은, 누락 사유 앞에 로데이터 파일이 없던 시기라는 내용을 붙입니다 (첫 로데이터('24.4.15 월)는 직전 근무일 4.12(금)~주말 글부터 담음 · 로데이터에 있는 글(Y)에는 붙이지 않음).
크롬 보안상 폴더 이름만 보이고, 크롬을 새로 켠 뒤 처음 저장할 때 '파일 수정 허용'을 한 번 물을 수 있습니다(허용을 누르세요).

2. 비교 파일 (온라인 동향 · 로데이터)
일일 온라인 동향 리스트와 로데이터 엑셀을 여러 개 한꺼번에 등록하세요(이 PC 크롬에 보관, 다시 넣지 않아도 됨). 파일 안의 카페 글 주소(카페 영문 주소 + 글번호로 비교 · 주소 뒤 꼬리·새 카페 주소 모양이 달라도 같은 글로 봄 · naver.me 짧은 주소는 풀어서 비교)로 각 게시물이 들어 있었는지 확인해 엑셀 '포함 여부' 칸에 온라인동향 / 로데이터 순서로 Y / N 을 씁니다. 종류는 머리글(불만구분·중복 → 온라인 동향, 주요 내용 → 로데이터)로 자동으로 정하며 바꿀 수 있습니다.

3. Claude AI 설정 (요약 · 누락 사유)
본문을 읽은 뒤 AI 가 주제에 맞는 글인지 다시 판단하고, 주요내용 요약과 누락 사유를 씁니다. 끄면 정해진 규칙 문장으로 씁니다.
API 키는 이 PC 크롬에만 저장되고, 요약을 위해 체크한 글의 제목·본문이 Anthropic(Claude)으로 보내집니다. API 키는 console.anthropic.com 에서 만들 수 있습니다.

4. 결과 확인 · 본문 요약 · 엑셀 받기

시트 단어와 위험 단어가 함께 있는 글이 체크됩니다. 필요 없는 글은 체크를 풀거나 삭제하세요. 체크된 글만 다음 단계와 엑셀에 들어갑니다.
차종게시일동호회제목주요내용 요약동향 / 로데이터누락 사유비고

본문 읽기 · 요약

체크한 글을 하나씩 열어 본문을 읽고(글 하나에 10초 안팎), 주요내용 요약과 온라인 동향 미포함(N) 글의 누락 사유를 씁니다(로데이터에도 없는 N / N 글은 로데이터에 수집되지 않은 이유). AI 를 쓰면 본문 내용을 보고 AI 가 체크 여부를 최종 판단하고(직접 체크·해제한 글은 그대로), 쓰지 않으면 본문의 단어로 정합니다. 이미 읽은 글은 다시 열지 않습니다. AI 사용 여부·키는 위 3번에서 정합니다.
💰 = 누르면 Claude AI 비용이 드는 버튼 (실행 전에 예상 비용을 보여주고 확인을 받음)

엑셀 받기

순서대로 누르면 됩니다. ① 로우 엑셀(찾은 글 전체) → ② 1차 검수(체크한 글 + 주제 관련도 % · 70% 이상 빨강) → ③ 최종 파일(검수를 통과한 글만). 데이터 DB 에도 따로 보관합니다. ② 를 누르면 검수가 안 된 글을 AI 가 판독된 내용(요약·상황·본문 일부)으로 먼저 검수(관련도 + 4항목)하고, ③ 은 그 결과를 그대로 씁니다(본문을 다시 읽지 않음 · 검수 비용은 한 번). 💰 는 검수할 글이 남아 있을 때만 붙습니다.

네이버 카페는 계정 보호를 위해 검색 화면과 게시글을 하나씩 열어 사람처럼 천천히 읽습니다. 창·탭은 띄우지 않고 이 화면 안의 보이지 않는 곳에서 읽습니다. 오래 걸리는 작업이니 중간에 멈추거나 화면을 닫아도, 다시 열면 이어서 할 수 있습니다. 내가 열람할 수 있는 글만 찾을 수 있습니다(로그인 필요).
