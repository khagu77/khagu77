2. 비교 파일 (온라인 동향 · 로데이터)

일일 온라인 동향 리스트와 로데이터 엑셀을 여러 개 한꺼번에 등록하세요(이 PC 크롬에 보관, 다시 넣지 않아도 됨). 파일 안의 카페 글 주소(카페 영문 주소 + 글번호로 비교 · 주소 뒤 꼬리·새 카페 주소 모양이 달라도 같은 글로 봄 · naver.me 짧은 주소는 풀어서 비교)로 각 게시물이 들어 있었는지 확인해 엑셀 '포함 여부' 칸에 온라인동향 / 로데이터 순서로 Y / N 을 씁니다. 종류는 머리글(불만구분·중복 → 온라인 동향, 주요 내용 → 로데이터)로 자동으로 정하며 바꿀 수 있습니다.

3. Claude AI 설정 (요약 · 누락 사유)

본문을 읽은 뒤 AI 가 주제에 맞는 글인지 다시 판단하고, 주요내용 요약과 누락 사유를 씁니다. 끄면 정해진 규칙 문장으로 씁니다.
API 키는 이 PC 크롬에만 저장되고, 요약을 위해 체크한 글의 제목·본문이 Anthropic(Claude)으로 보내집니다. API 키는 console.anthropic.com 에서 만들 수 있습니다.

체크한 글을 하나씩 열어 본문을 읽고(글 하나에 10초 안팎), 주요내용 요약과 온라인 동향 미포함(N) 글의 누락 사유를 씁니다. 본문에 관련 단어가 없으면 체크를 풀어 둡니다. 이미 읽은 글은 다시 열지 않습니다. AI 사용 여부·키는 위 3번에서 정합니다.
