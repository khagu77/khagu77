# 판단 규칙 (LX3 / ME1 / MX5 전동 시트 작동 위험 상황 관련 게시물 수집)

프로그램이 글을 고르고, 포함 여부를 정하고, 요약·누락 사유를 쓰는 기준입니다.
담당자 기준이 새로 생기면 이 문서와 화면의 **설정 → AI 추가 규칙 (메모)** 에 함께 적습니다
(메모는 요약·누락 사유를 쓸 때마다 AI 에게 그대로 전달되고, 기본 규칙보다 우선합니다).

## 조사 주제
아이오닉9(ME1)·팰리세이드(LX3)·싼타페(MX5)의 2열·3열 시트를 조작할 때(전동 폴딩·원터치 워크인·슬라이딩·리클라이닝·복귀 등)
안전 사고가 발생했거나, 발생할 뻔했거나, 발생할 우려·가능성을 언급한 네이버 동호회 게시물.

- 수집 기간: 차종별 양산 시점부터 — LX3 '24.12.20 · ME1 '24.12.16 · MX5 '23.8.15
- **꼭 넣을 글**(요청서 예시 게시물)은 검색·판단과 상관없이 넣습니다.

## 관련 글 고르기
1. 검색 결과의 제목·미리보기에 **시트 단어 + 위험 단어**가 함께 있으면 체크.
2. **AI 1차 검토**: 체크 안 된 글도 제목·미리보기 내용으로 다시 보고, 시트·안전 단서가 있고 주제와 이어질 수 있으면 체크(애매하면 체크).
3. 본문을 읽은 뒤 **AI 최종 판단**: 본문 내용으로 체크 여부를 정함(직접 체크·해제한 글은 그대로).
   - 해당: 2·3열 시트 조작·작동 중 사람·반려동물·물건의 끼임·눌림·부딪힘·부상, 그럴 뻔한 상황, 위험 우려·주의 당부, 안전장치 작동 의문, 관련 리콜·업데이트 소식
   - 해당 없음: 1열만의 이야기, 카시트 제품, 시트 가죽·열선·통풍·소음·편의성만의 이야기, 판매·구매, 조사 차종과 무관한 글

## 포함 여부 (온라인동향 / 로데이터)
- 같은 글인지는 **카페 영문 주소 + 글번호**로 봅니다(주소 꼬리·새 카페 주소 모양이 달라도 같은 글, naver.me 짧은 주소는 풀어서 비교).
- 표기: `N / N` · `N / Y` · `Y / Y` (Y 파랑 · N 빨강).
- `Y / N` 은 나올 수 없는 조합입니다(로데이터에 없는 글로는 일일동향을 쓸 수 없음). 나오면 로데이터 파일이 빠졌는지 확인합니다.

## 주요내용 요약
- 한 문장, 40~120자, 사내 온라인 동향 보고서 문체로 "~하는 내용" 으로 끝냄.
- 누가 · 어떤 시트 조작 중 · 무슨 일이(끼임·부상·뻔함) · 글쓴이의 요구·반응을 글에 있는 만큼만. 글에 없는 사실은 쓰지 않음.

## 미포함시 누락 사유 (온라인 동향에 없는 글만)
- 한 문장, "~로 추정" 으로 끝냄. 글 내용에 근거한 이유를 씀. 예)
  - 실제 사고가 아닌 사용 시 주의 당부·위험 우려 수준의 글
  - 끼임 직전의 아차 상황으로 실제 부상·파손이 없음
  - 경미한 부상이나 작동 중 신체를 넣은 사용 부주의 사례
  - 안전장치 작동 방식에 대한 단순 문의
  - 언론 기사·리콜 공지 공유 글
  - 로데이터에는 있으면 "로데이터에는 수집되었으나, …" 로 시작
- 비교한 온라인 동향 파일의 기간 밖 글은 추정하지 않고 "해당 기간 동향 파일 확인 필요".
