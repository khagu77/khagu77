# 현대차 이슈 모니터링 수집 도우미 (크롬 확장)

뽐뿌처럼 **서버 접속을 막는 게시판**을 담당자 PC의 크롬이 평소처럼 읽어, 새 글만 모니터링 시스템으로 보냅니다.

## 설치
1. 시스템 → 설정 → 🔐 API 키 → **크롬 수집 도우미**에서 '토큰 만들기' → 토큰 복사, '확장 내려받기'
2. 받은 zip 을 풀고 크롬 주소창 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기 → **압축해제된 확장 프로그램을 로드합니다** → 푼 폴더 선택
3. 크롬 오른쪽 위 퍼즐 아이콘 → 수집 도우미 핀 고정 → 눌러서 **수집 토큰** 붙여넣기 → 저장 → 지금 수집

크롬이 켜져 있는 동안 5분마다 자동으로 수집합니다. 여러 PC에 설치해도 같은 글은 시스템이 한 번만 저장합니다.
