싼타페 페이스리프트(MX5 F/L) 가격 언급 게시물 수집

설치안내서 · 크롬 확장프로그램 (윈도우 · 맥 공통)

무엇을 하나요?

싼타페 동호회 3곳(싼타페MX5패밀리 · 클럽싼타페 · 싼타페MX5클럽)에서 싼타페 F/L 예상 가격을 언급한 글을 기간을 정해 모두 모으고, 아반떼·투싼 가격 공개 전후로 예상 가격 여론이 어떻게 바뀌었는지 엑셀 보고서(게시물 · 구간별 여론 · 주별 추이)로 정리합니다. 현행 차량의 가격만 이야기한 글은 넣지 않습니다.

설치 (최초 1회)

  1. 받은 압축 파일을 풉니다. 안의 MX5FL_가격여론수집기_확장프로그램 폴더를 지우거나 옮기지 않을 곳(예: 문서 폴더)에 둡니다.
  2. 크롬 주소창에 chrome://extensions 를 입력합니다.
  3. 오른쪽 위 개발자 모드 스위치를 켭니다.
  4. 왼쪽 위 압축해제된 확장 프로그램을 로드합니다 → 위 폴더를 선택합니다.
  5. 오른쪽 위 퍼즐 아이콘 → 싼타페 아이콘 옆 핀을 눌러 고정합니다. 아이콘을 누르면 수집 화면이 새 탭으로 열립니다.
새 버전으로 바꿀 때는 확장을 삭제하지 말고, 쓰던 폴더에 새 파일을 덮어쓴 뒤 chrome://extensions 에서 새로고침(↻)하세요. 삭제하면 찾은 글·데이터 DB 가 함께 지워집니다.

사용 순서

  1. 크롬에서 네이버에 로그인해 둡니다.
  2. 기간 · 기준 사건을 확인합니다. 기준 사건 기본값: 2026-08-05 아반떼 가격 공개 · 2026-10-21 투싼 가격 공개. 기간은 처음에 첫 사건 30일 전 ~ 오늘입니다.
  3. 게시물 찾기 → 동호회마다 검색어를 하나씩 검색합니다(사람처럼 천천히 · 중간에 멈춰도 다시 누르면 이어서).
  4. 본문 읽고 요약하기 → 글마다 본문 · 작성자 닉네임 · 조회수 · 댓글수를 읽고 요약합니다.
  5. (선택) 2. Claude AI 설정에 API 키를 넣으면 AI 가 예상 가격 여론(긍정·중립·부정) · 예상 인상 폭 · 비교 차종 · 구매 영향을 판단하고, 💰 여론 변화 보고 쓰기로 보고 요지를 씁니다.
  6. 엑셀 받기 → 보고 엑셀을 받고, 오른쪽 위 🗄 데이터 DB에 날짜별로 보관됩니다(AI 비용 · 소요 시간 포함).
