부정 이슈 모니터링 설치·사용 안내서

크롬 확장프로그램 「현대차·제네시스 부정 이슈 모니터링」 · 네이버 카페·자동차 커뮤니티 새 글 → 보고서 엑셀

1. 무엇을 하나요?

  • 설정한 네이버 카페와 자동차 커뮤니티(보배드림·클리앙·뽐뿌)의 정해진 기간(기본: 전일 08:00 ~ 금일 08:00) 새 글을 훑어봅니다.
  • 현대차·제네시스 부정 이슈(품질·응대·결품) 글만 골라 커뮤니티명 / 차종 / 게시일 / 구분 / URL / 주요 내용 양식의 엑셀로 저장합니다.
  • 노란색 표시 항목(기본: 팰리세이드 LX3 전동 시트 관련)에 해당하면 '주요 내용' 칸을 노란색으로 칠합니다.
  • 매일 정해진 시각(기본 06:00)에 자동으로 수집해 다운로드 폴더에 저장할 수 있습니다.

2. 설치 (처음 한 번만)

① 압축 풀기

  1. 부정이슈모니터링.zip → 마우스 오른쪽 클릭 → [압축 풀기].
  2. 압축을 푼 폴더를 지우지 않을 곳(예: 문서 폴더)에 둡니다. 지우거나 옮기면 확장이 사라집니다.

② 크롬에 올리기

  1. 크롬 주소창에 chrome://extensions 입력 → 오른쪽 위 개발자 모드 켜기.
  2. 압축해제된 확장 프로그램을 로드합니다 → 부정이슈모니터링_확장프로그램 폴더 선택.
  3. 퍼즐 아이콘 → 「부정 이슈 모니터링」 옆 핀(📌)을 눌러 고정합니다.

③ Claude API 키 넣기 (AI 판정·요약을 쓸 때)

  1. https://platform.claude.com 로그인 → Settings → Billing 에서 크레딧 충전.
  2. Settings → API Keys → Create Key 로 만든 sk-ant-… 키를 복사합니다. (한 번만 보입니다)
  3. 확장 아이콘 → [설정] 탭 → API 키 칸에 붙여넣고 키 확인 → 설정 저장.
키는 이 PC 의 크롬 안에만 저장됩니다. 메신저·메일로 보내지 마세요. 키가 없으면 키워드 모드(무료)로만 동작합니다.
새 버전으로 업데이트할 때: 확장을 삭제하지 마세요(API 키·설정·데일리 DB 가 함께 지워집니다). 새 zip 을 풀어 부정이슈모니터링_확장프로그램 폴더 안의 파일을 지금 쓰는 폴더에 덮어쓴 뒤, chrome://extensions 에서 이 확장의 ↻(새로고침)을 누르세요. 수집 중에는 업데이트하지 마세요.

3. 처음에는 이렇게 시험하세요 (무료 → 소량 → 전체)

  1. 무료 시험: 수집 화면에서 「AI 사용」 체크를 끄고, 「이번에 수집할 곳 고르기」 → 시험용 (카페 2곳 + 커뮤니티 1곳) → 최근 3시간 → 수집 시작.
    → 카페·커뮤니티 글이 잘 읽히는지(진행 표의 '기간 내 글' 숫자) 확인합니다. 이 모드에서 '주요 내용'은 글 제목입니다.
  2. AI 소량 시험: 같은 조건에서 「AI 사용」을 켜고 수집 → 끝난 뒤 화면에 실제 AI 비용이 나옵니다.
  3. 문제가 없으면 기본 기간·전체 카페로 수집하고, 자동 수집을 켭니다.

4. 매일 사용

자동 수집 (권장)

  • [설정] → 「매일 자동으로 수집」 체크, 시작 시각(기본 06:00) → 저장.
  • 그 시각에 수집 탭이 뒤쪽에 열려 30~60분 수집한 뒤, 다운로드 폴더에 261011_현대차 제네시스 커뮤니티 부정이슈.xlsx 형식으로 저장하고 알림을 띄웁니다.
  • 수집 기간: 자동 수집은 지난 자동 수집이 끝난 시각부터 지금까지를 모읍니다(예: 06:00 실행이면 전일 06:00 ~ 금일 06:00). 매일 이어서 모으므로 빠지거나 겹치는 글이 없습니다. 직접 수집할 때의 기본값은 전일 08:00 ~ 금일 08:00 입니다.
  • 조건: 그 시각에 PC 가 켜져 있고(절전 X), 크롬이 실행 중이며, 네이버에 로그인돼 있어야 합니다. 그 시각에 꺼져 있었다면, 그날 정오 전에 크롬을 켜면 그때 한 번 수집합니다.
  • 윈도우 설정 → 시스템 → 전원 에서 절전 시간을 '안 함'으로 하거나, 수집 시간대에 PC 가 깨어 있게 해 주세요.

직접 수집

  • 확장 아이콘 → 기간 확인 → 수집 시작. 수집 중 열리는 네이버 탭과 수집 화면 탭은 닫지 마세요.
  • 끝나면 결과 표에서 차종·구분·주요 내용·노란색을 고치거나 지운 뒤 엑셀 받기.
  • 기간은 언제든 바꿔서 다시 수집할 수 있습니다.

5. 보고 필요 · 이어서 작성 · 데일리 DB · 명령 프롬프트

  • 보고 필요: 네이버 카페 글 중 꼭 보고해야 할 심각한 이슈 4~6건을 AI 가 고릅니다(신차 우선, 단순 정보 공유 제외). 결과 표 '보고 필요' 칸에 ✅, 엑셀 G열에 + 가 들어갑니다. 칸을 눌러 직접 고칠 수 있습니다.
  • 이어서 작성: 수집 화면에서 데일리 DB 의 이전 결과나 기존 엑셀 파일을 고르면, 그 데이터 뒤에 이번 결과를 붙여 합본으로 저장합니다. 같은 게시물은 처음 것만 남기고, 파일 이름은 이번 수집 날짜로 됩니다.
  • 데일리 DB: 수집할 때마다 결과가 저장됩니다. 회차별로 엑셀 받기·결과 보기·이어받기·삭제를 할 수 있습니다.
  • 명령 프롬프트: AI 에 실제로 보내는 프롬프트를 확인하고, 추가 지시사항을 적어 저장하면 다음 수집부터 적용됩니다(최종 업데이트 시각과 수정 이력 표시).
  • 수집이 끝나면 수집 시작·완료 시각과 소요 시간이 빨간 글씨로 표시됩니다.

6. 설정

항목설명
네이버 카페카페 이름(엑셀 표시명), 카페 ID(cafe.naver.com/이부분), 기본 차종(그 카페 글의 차종을 모를 때 쓰는 코드). 추가·수정·삭제·사용 끄기 가능.
게시판 지정: 비우면 카페 전체 게시판. 숫자는 게시판 번호(게시판 주소의 menus/숫자, 주소를 그대로 붙여넣어도 됨), 그룹:이름 은 카페 왼쪽 메뉴의 그 묶음 아래 게시판 전부, 그 밖의 글자는 게시판 이름입니다. 쉼표로 구분. 기본값: 영운모 그룹:현대/기아 트럭, 전기차 동호회 전기차자유게시판, 전기차 Q&A, 그룹:현대차 EV, 넥쏘 카페 101, 31, 688, 아이오닉 멤버스 1259, 1258, 78, 아이오닉5Q&A, 아이오닉6Q&A, 아이오닉9Q&A.
검색 경유: 카페에서 바로 열면 안 보이는 글이 많은 카페(기본: 넥쏘 카페, 영운모)는 글 제목을 네이버 검색(카페 탭)에서 찾아 그 링크로 들어가 읽습니다. 다른 카페도 바로 못 읽은 글은 같은 방법으로 한 번 더 시도합니다.
자동차 커뮤니티이름과 게시판 목록 주소. 보배드림·클리앙·뽐뿌는 다른 게시판 주소로 바꿔도 됩니다.
엑셀 파일 이름{날짜} 자리에 수집 끝 날짜(예: 261011)가 들어갑니다. 지금 쓰시는 파일 이름에서 날짜만 {날짜}로 바꿔 넣으면 됩니다.
노란색 표시차종 코드 + 내용. 해당하는 글의 '주요 내용' 칸을 노란색으로 칠합니다.
차종 코드표코드: 차종명, 별칭 한 줄에 하나. AI 가 이 표로 차종 코드를 정합니다.
모델Opus 5.5(가장 정확) / Sonnet 5.5 / Haiku 5.5(가장 저렴). 처음 며칠 비교해 보고 정하세요.
네이버 읽는 속도'느리게'는 대기 시간이 2배라 더 안전하지만 오래 걸립니다.

7. 네이버 계정 보호를 위한 동작

  • 네이버 API 를 직접 부르지 않고, 백그라운드 탭 하나로 카페 화면(전체글보기, 게시글)을 사람처럼 차례로 열어 읽습니다.
  • 화면 사이 3~10초, 카페 사이 4~8초를 무작위로 쉬고, 8개 카페마다 20~40초 쉽니다. 카페 순서도 매번 섞습니다.
  • 모든 글을 열지 않고, 제목으로 고른 후보 글만 본문을 엽니다. 한 번에 여는 화면 수에도 상한이 있습니다.
  • 로그인 풀림·보호조치·자동입력 방지 화면이 보이면 네이버 수집을 즉시 멈추고, 커뮤니티 결과와 그때까지 모은 카페 결과로 엑셀을 만듭니다.
  • 그래도 보호조치가 걸리면: 수집을 멈추고 본인 확인·비밀번호 변경으로 해제한 뒤 며칠 쉬고, 속도를 '느리게'로 바꾸세요.

8. 자주 묻는 것

상황해결
카페가 '실패: 글 목록을 읽지 못했습니다'카페 ID 확인. 진행 기록을 펼쳐 기록 복사 를 누르고 붙여넣어 전달해 주세요([진단] 줄에 원인이 남습니다).
'건너뜀 (네이버 로그인 필요)'크롬에서 네이버에 로그인한 뒤 다시 수집.
AI 비용이 궁금함수집이 끝나면 맨 위 요약 줄에 그 회차 비용이 나옵니다.
AI 오류(키·크레딧)[설정] → 키 확인. 크레딧 부족이면 Billing 에서 충전. AI 가 실패한 묶음은 키워드로 대신 판정합니다.

수집한 게시글은 각 사이트 이용약관과 개인정보보호법을 지켜 내부 보고 용도로만 사용하세요.
