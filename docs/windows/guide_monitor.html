온라인 오전 일일동향 수집 및 보고서 작성 설치·사용 안내서

크롬 확장프로그램 「온라인 오전 일일동향 수집 및 보고서 작성」 · 부정 이슈 수집 → 엑셀 → PPT 보고서 → RAW data 엑셀을 한 프로그램에서

1. 무엇을 하나요?

  • 설정한 네이버 카페와 자동차 커뮤니티(보배드림·클리앙·뽐뿌)의 정해진 기간(기본: 전일 07:30 ~ 금일 07:30, 수집 화면의 「이 시각을 기본값으로 저장」이나 설정에서 바꿀 수 있음) 새 글을 훑어봅니다.
  • 현대차·제네시스 부정 이슈(품질·응대·결품) 글만 골라 커뮤니티명 / 차종 / 게시일 / 구분 / URL / 주요 내용 양식의 엑셀로 저장합니다.
  • 노란색 표시 항목(기본: 팰리세이드 LX3 전동 시트 관련)에 해당하면 '주요 내용' 칸을 노란색으로 칠합니다.
  • 매일 정해진 시각(기본 06:00)에 자동으로 수집해 다운로드 폴더(또는 설정에서 지정한 폴더)에 저장할 수 있습니다.
  • PPT·RAW 작성 탭(예전 「온라인 오전동향 PPT 보고서 작성기」를 합친 것): + 표시 글을 캡처·요약해 YYMMDD_현대차 온라인 이슈 보고서.pptx를 만들고, YYMMDD_차종별 온라인 동향 raw data.xlsx를 이어 씁니다.

1-1. 하루 순서 (원스톱)

  1. 수집 탭: 자동 수집 또는 [수집 시작] → 결과 표에서 삭제·보고 필요(+) 확인 → [엑셀 받기].
  2. [PPT·RAW 작성으로 →] (또는 위쪽 PPT·RAW 작성 탭)
    • 수집 모드 전체: 방금 검토한 결과 표를 그대로 넘겨받습니다 (엑셀 첨부 필요 없음).
    • 수집 모드 1인용: 결과 표를 넘기지 않습니다. 담당자들이 합친 전체(통합) 엑셀을 첨부해야 [캡처·요약 시작]·[RAW 받기]가 눌립니다.
    • PPT 와 RAW 는 같은 전체 엑셀(전체 모드면 결과 표, 1인용이면 첨부 파일)로 만듭니다.
  3. [캡처·요약 시작] → 미리보기 확인·수정 → [PPT 받기] → [RAW data 엑셀 파일 받기]. 「캡처·요약이 끝나면 PPT·RAW 바로 저장」을 켜면 끝나자마자 둘 다 저장하고 한 번에 알려 줍니다.

결과 창을 비웠거나 어제 결과를 함께 보고 싶을 때: 수집 버튼 줄의 [이전 기록 불러오기] → 합칠 데일리 DB 기록(오늘·어제 등)을 체크 → [불러오기]. 같은 게시물은 하나만, 동호회별·날짜순으로 정리됩니다. 수집을 이미 시작한 뒤 어제 엑셀·DB 를 붙이려면 「이어서 작성」에서 고르고 [지금 결과에 합치기]. 데일리 DB 기록은 처음 고치기 전 원본을 보관하므로 데일리 DB 탭의 [원본 복구]로 되돌릴 수 있습니다.

결과 표에서 고치면: 저장 버튼 없이 바로 자동 저장됩니다 (결과 제목 옆 「✓ 자동 저장됨」). 그 수집의 데일리 DB 항목에도 반영되어 다음 날 「이어서 작성」에서 고른 DB 도 고친 그대로 이어집니다. 고친 차종·구분·주요 내용·노란색·보고 필요와 지운 글, 그리고 PPT 미리보기에서 고친 문구(본문 요약·댓글 반응·요약표 내용·페이지 제목·제원·불만 구분·신규/중복·지역 등)는 자동 학습 메모(명령 프롬프트 탭)에 쌓여 다음 판정·PPT 작성부터 AI 에 「담당자 수정 사례」로 전달됩니다. 잘못 쌓인 사례는 거기서 지울 수 있습니다. 넥쏘 카페·영운모처럼 바로 열면 안 보이는 글은 결과 표 링크(앞에 네이버 카페 아이콘)가 네이버 검색 결과로 열립니다. 표시 글자와 엑셀·PPT·RAW 에는 원본 주소가 들어갑니다.

처음 한 번: PPT·RAW 작성 탭의 ⚙ 설정에서 보고서 템플릿 PPT와 지난 RAW data 엑셀을 넣어 주세요 (예전 PPT 작성기에 넣어 둔 것은 다른 확장이라 옮겨지지 않습니다). API 키와 저장 폴더는 수집 쪽 설정을 같이 씁니다. 수집이 진행 중일 때는 PPT 캡처를 시작할 수 없습니다. 예전 PPT 작성기는 합친 버전이 잘 되는 것을 확인할 때까지 지우지 말고 꺼 두기만 하세요.

2. 설치 (처음 한 번만)

① 압축 풀기

  1. 부정이슈모니터링.zip → 마우스 오른쪽 클릭 → [압축 풀기].
  2. 압축을 푼 폴더를 지우지 않을 곳(예: 문서 폴더)에 둡니다. 지우거나 옮기면 확장이 사라집니다.

② 크롬에 올리기

  1. 크롬 주소창에 chrome://extensions 입력 → 오른쪽 위 개발자 모드 켜기.
  2. 압축해제된 확장 프로그램을 로드합니다 → 부정이슈모니터링_확장프로그램 폴더 선택.
  3. 퍼즐 아이콘 → 「부정 이슈 모니터링」 옆 핀(📌)을 눌러 고정합니다.

③ Claude API 키 넣기 (AI 판정·요약을 쓸 때)

  1. https://platform.claude.com 로그인 → Settings → Billing 에서 크레딧 충전.
  2. Settings → API Keys → Create Key 로 만든 sk-ant-… 키를 복사합니다. (한 번만 보입니다)
  3. 확장 아이콘 → [설정] 탭 → API 키 칸에 붙여넣고 키 확인 → 설정 저장.
키는 이 PC 의 크롬 안에만 저장됩니다. 메신저·메일로 보내지 마세요. 키가 없으면 키워드 모드(무료)로만 동작합니다.
새 버전으로 업데이트할 때: 확장을 삭제하지 마세요(API 키·설정·데일리 DB 가 함께 지워집니다). 새 zip 을 풀어 부정이슈모니터링_확장프로그램 폴더 안의 파일을 지금 쓰는 폴더에 덮어쓴 뒤, chrome://extensions 에서 이 확장의 ↻(새로고침)을 누르세요. 수집 중에는 업데이트하지 마세요.

3. 처음에는 이렇게 시험하세요 (무료 → 소량 → 전체)

  1. 무료 시험: 수집 화면에서 「AI 사용」 체크를 끄고, 「이번에 수집할 곳 고르기」 → 시험용 (카페 2곳 + 커뮤니티 1곳) → 최근 3시간 → 수집 시작.
    → 카페·커뮤니티 글이 잘 읽히는지(진행 표의 '기간 내 글' 숫자) 확인합니다. 이 모드에서 '주요 내용'은 글 제목입니다.
  2. AI 소량 시험: 같은 조건에서 「AI 사용」을 켜고 수집 → 끝난 뒤 화면에 실제 AI 비용이 나옵니다.
  3. 문제가 없으면 기본 기간·전체 카페로 수집하고, 자동 수집을 켭니다.

4. 매일 사용

자동 수집 (권장)

  • [설정] → 「매일 자동으로 수집」 체크, 시작 시각(기본 06:00) → 저장.
  • 그 시각에 수집 탭이 뒤쪽에 열려 30~60분 수집한 뒤, 다운로드 폴더에 261011_차종별 온라인 동향_통합.xlsx 형식으로 저장하고 알림을 띄웁니다.
  • 저장 폴더 지정: 설정 → 엑셀 저장 폴더 → 폴더 선택에서 원하는 폴더를 고르고 '편집 허용'을 누르면 그 폴더에 바로 저장됩니다. 크롬이 권한을 물으면 '방문할 때마다 허용'을 고르세요. 맥에서 처음 저장할 때 'Chrome이 데스크탑 폴더에 접근하려고 합니다'가 뜨면 허용합니다. 권한이 풀리면 다운로드 폴더에 대신 저장되고 기록에 빨간 글로 알려 주며, 설정에서 '저장 권한 다시 허용'을 한 번 누르면 됩니다.
  • 맥 '정보 가져오기'의 출처(chrome-extension://…) 지우기: 크롬이 저장하는 모든 파일에 macOS 가 출처 기록을 붙입니다 (엑셀 내용에는 없음, 메일·메신저로 보내면 따라가지 않음). 저장 폴더에서 자동으로 지우려면: Automator → 새로운 문서 → 폴더 동작 → 위쪽 폴더를 저장 폴더로 선택 → 왼쪽에서 '셸 스크립트 실행'을 끌어다 놓고 '입력 전달'을 인수로 → 아래 내용을 붙여 넣고 저장(이름: 출처 지우기). 
    sleep 5
for f in "$@"; do xattr -d com.apple.metadata:kMDItemWhereFroms "$f" 2>/dev/null; done
    이미 저장된 파일은 터미널에서 한 번: xattr -rd com.apple.metadata:kMDItemWhereFroms "저장폴더 경로"
  • 수집 기간: 자동 수집은 지난 자동 수집이 끝난 시각부터 지금까지를 모읍니다(예: 06:00 실행이면 전일 06:00 ~ 금일 06:00). 매일 이어서 모으므로 빠지거나 겹치는 글이 없습니다. 직접 수집할 때의 기본값은 전일 07:30 ~ 금일 07:30 입니다 (근무일 보고서 모드면 월요일은 금요일 07:30부터).
  • 조건: 그 시각에 PC 가 켜져 있고(절전 X), 크롬이 실행 중이며, 네이버에 로그인돼 있어야 합니다. 그 시각에 꺼져 있었다면, 그날 정오 전에 크롬을 켜면 그때 한 번 수집합니다.
  • 윈도우 설정 → 시스템 → 전원 에서 절전 시간을 '안 함'으로 하거나, 수집 시간대에 PC 가 깨어 있게 해 주세요.

근무일 보고서 모드 (기본 켜짐)

  • 근무일(기본 월~금, 휴일 목록 제외) 아침 자동 수집 때만 엑셀을 받습니다. 주말·공휴일에 자동 수집한 것은 데일리 DB 에 쌓아 두었다가 다음 근무일 아침에 합본으로 받습니다(같은 게시물은 처음 것만, 보고 필요는 합본 전체에서 다시 4~6건).
  • 예) 월요일 아침 파일 = 금요일 아침 이후 토·일·월 새벽 수집분 합본. 연휴·대체공휴일도 같은 방식.
  • 설정 → 자동 수집에서 근무 요일과 공휴일·회사 휴무일 목록을 고칠 수 있습니다(음력 공휴일·대체공휴일은 해마다 확인).
  • '주말·휴일에도 미리 수집'을 끄면 휴일에는 쉬고, 다음 근무일 아침에 한꺼번에 수집합니다(그날은 오래 걸리니 시작 시각을 앞당기세요).

수집 모드: 전체 / 1인용

  • 전체: 설정의 모든 카페·자동차 커뮤니티를 수집합니다.
  • 1인용: 정해 둔 카페(기본: 전기차 동호회, 아이오닉 멤버스, 아이오닉9 오너스·클럽, 넥쏘 카페·책임보증 카페·오너스, 스타리아EV & ST1 클럽, 현대모터클럽, 영운모) + 자동차 커뮤니티 3곳만 수집합니다. '이번에 수집할 곳 고르기'에서 체크를 바꾼 뒤 지금 선택을 1인용으로 저장을 누르면 목록이 바뀝니다.
  • 1인용에서 파일명 앞 문구에 예를 들어 김 을 넣으면 김_261012_차종별 온라인 동향_통합.xlsx 로 받습니다.
  • 고른 모드는 PC 마다 기억되고, 그 PC 의 자동 수집도 같은 모드로 돕니다.

직접 수집

  • 확장 아이콘 → 기간 확인 → 수집 시작. 수집 중 열리는 네이버 탭과 수집 화면 탭은 닫지 마세요.
  • 끝나면 결과 표에서 차종·구분·주요 내용·노란색을 고치거나 지운 뒤 엑셀 받기.
  • 기간은 언제든 바꿔서 다시 수집할 수 있습니다.

5. 보고 필요 · 이어서 작성 · 데일리 DB · 명령 프롬프트

  • 보고 필요: 네이버 카페 글 중 꼭 보고해야 할 심각한 이슈 4~6건을 AI 가 고릅니다(신차 우선, 단순 정보 공유 제외). 결과 표 '보고 필요' 칸에 ✅, 엑셀 G열에 + 가 들어갑니다. 칸을 눌러 직접 고칠 수 있습니다.
  • 이어서 작성: 수집 화면에서 데일리 DB 의 이전 결과나 기존 엑셀 파일을 고르면, 그 데이터 뒤에 이번 결과를 붙여 합본으로 저장합니다. 같은 게시물은 처음 것만 남기고, 파일 이름은 이번 수집 날짜로 됩니다.
  • 데일리 DB: 수집할 때마다 결과가 저장됩니다. 회차별로 엑셀 받기·결과 보기·이어받기·삭제를 할 수 있습니다.
  • 명령 프롬프트: AI 에 실제로 보내는 프롬프트를 확인하고, 추가 지시사항을 적어 저장하면 다음 수집부터 적용됩니다(최종 업데이트 시각과 수정 이력 표시).
  • 수집이 끝나면 수집 시작·완료 시각과 소요 시간이 빨간 글씨로 표시됩니다.

6. 설정

항목설명

7. 네이버 계정 보호를 위한 동작

  • 네이버 API 를 직접 부르지 않고, 백그라운드 탭 하나로 카페 화면(전체글보기, 게시글)을 사람처럼 차례로 열어 읽습니다.
  • 화면 사이 3~10초, 카페 사이 4~8초를 무작위로 쉬고, 8개 카페마다 20~40초 쉽니다. 카페 순서도 매번 섞습니다.
  • 모든 글을 열지 않고, 제목으로 고른 후보 글만 본문을 엽니다. 한 번에 여는 화면 수에도 상한이 있습니다.
  • 로그인 풀림·보호조치·자동입력 방지 화면이 보이면 네이버 수집을 즉시 멈추고, 커뮤니티 결과와 그때까지 모은 카페 결과로 엑셀을 만듭니다.
  • 그래도 보호조치가 걸리면: 수집을 멈추고 본인 확인·비밀번호 변경으로 해제한 뒤 며칠 쉬고, 속도를 '느리게'로 바꾸세요.
