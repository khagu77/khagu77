블루핸즈/하이테크센터 정비 예약 관련 수집 시스템 설치·사용 안내서

크롬 확장프로그램 · 기사목록 파일의 네이버 카페 글 작성자를 확인해 주간 '정비 예약' 보고서 엑셀에 이어 쓰고, 받은 보고서를 DB 목록으로 모읍니다. (윈도우·맥 공통)

1. 설치 (처음 한 번만)

  1. 압축 파일을 풀고, 안의 블루핸즈수집기_확장프로그램 폴더를 지우지 않을 곳(예: 문서)에 둡니다.
  2. 크롬 주소창에 chrome://extensions → 오른쪽 위 개발자 모드 켜기.
  3. 압축해제된 확장 프로그램을 로드합니다 → 블루핸즈수집기_확장프로그램 폴더 선택.
  4. 퍼즐 모양 아이콘 → 「블루핸즈/하이테크센터 정비 예약 관련 수집 시스템」 옆 핀(📌)으로 고정합니다.

2. 매주 보고 (월요일 · 월요일이 쉬는 날이면 다음 근무일)

보고일인데 아직 보고서를 받지 않았으면 아이콘에 보고가 표시됩니다. 화면 위쪽에 이번·다음 보고일이 나옵니다.
  1. 크롬에서 네이버에 로그인해 둡니다.
  2. 블루핸즈 아이콘 → 기사목록 파일에 모니터링 사이트에서 받은 기사목록YYYYMMDD.xls를 고릅니다.
  3. 지난 보고서 파일에 가장 최근의 YYYYMMDD_정비 예약 …xlsx를 고릅니다. 이미 보고서에 있는 글은 흐리게 건너뜁니다.
  4. 작성자 확인 시작 → 새 글을 하나씩 탭으로 열어(잠깐 열렸다 닫힘) 작성자를 읽습니다. 글 하나에 10~20초.
    • 본문이 안 보이면 네이버 검색 카페 탭에서 제목으로 같은 글을 찾아 그 링크로 들어가 확인합니다.
    • 넥쏘카페·영운모는 처음부터 검색으로 들어갑니다(설정에서 바꿀 수 있음).
    • 그래도 못 보면 패스 - 엑셀에 넣지 않습니다. 직접 알면 작성자 칸에 써 넣어도 됩니다.
    • 삭제된 게시물(“삭제되었거나 존재하지 않는 게시글” 안내·알림창)은 목록에 빨간 취소선으로 표시하고 엑셀에는 넣지 않습니다(연번도 주지 않음). 잘못 판단했으면 [되돌리기].
    • 확인된 작성자 닉네임은 목록에 굵게 보입니다. 틀리면 [수정].
  5. 엑셀 받기 → 지난 보고서 아래에 날짜순으로 연번·채널(동호회)·채널명·작성일·제목·작성자·URL(https://cafe.naver.com/카페주소/글번호)을 이어 쓰고, 파일명 앞 날짜를 오늘로 바꿔 저장합니다. 서식은 바로 위 행과 같습니다.
작업 중에는 맨 위에 진행 막대가 보입니다. 글은 화면에 띄우지 않고 읽으므로 탭·창이 뜨지 않고, 뒤로 가기는 막혀 있습니다. 실수로 창을 닫거나 오류가 나도 다시 열면 이어서 진행으로 남은 글부터 확인합니다(처음부터 다시 하지 않음). 엑셀 아래에는 전주 대비 누적 건수가 ▲ NN 건 / ▼ NN 건으로 나옵니다.

연번은 기본으로 새 글 전체에 날짜순으로 붙고 패스한 글 번호는 비어 있게 됩니다(설정에서 끌 수 있음).

3. 보고서 DB 목록

  • 엑셀을 받을 때마다 파일의 모든 행이 이 PC 크롬에 저장됩니다. 위쪽 보고서 DB 목록에서 검색·기간으로 찾고, 보이는 목록을 같은 양식 엑셀로 받을 수 있습니다.
  • 지난 보고서 파일들은 보고서 엑셀을 DB에 넣기로 한 번에 넣을 수 있습니다.
  • 지난 보고서 파일을 고르지 않고 엑셀을 받으면 DB 목록 전체 + 이번 글로 파일을 만듭니다.
