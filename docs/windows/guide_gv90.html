GV90(JG1) 온라인 게시물 일일 수집 설치·사용 안내서

크롬 확장프로그램 「GV90(JG1) 온라인 게시물 일일 수집」 · 언론·동호회·유튜브·자동차 커뮤니티의 GV90 관련 게시물을 매일 모아 raw data 엑셀 · 데일리 DB · 대시보드로 정리 (윈도우·맥 공통)

1. 무엇을 하나요?

  • 매일 GV90 관련 게시물 수집: 언론(네이버 뉴스) · 동호회(네이버 카페 49곳) · 유튜브(모니터링 채널 48개 + 검색) · 자동차 커뮤니티(보배드림·클리앙·뽐뿌). 수집 채널은 「이슈 모니터링 보고서 작성」과 같은 목록입니다.
  • 항목: 커뮤니티명 · 차종 · 게시일 · 구분(품질·디자인·가격 등) · URL · 주요 내용 · 성향(긍정 / 중립 / 부정 / 단순비난) · 조회수 · 댓글 수
  • 엑셀: 「온라인 오전 일일동향」 RAW data 양식(제네시스 시트 · 연번·커뮤니티명·차종·게시일·구분·게시글 위치·주요 내용)에 성향 열을 붙여 저장합니다.
  • 시간·자동 수집·휴일: 「온라인 오전 일일동향」과 같습니다 — 수집 기간 기본 전일 07:30 ~ 금일 07:30, 매일 06:00 자동 수집, 휴일엔 수집만 해 두고 다음 근무일 엑셀에 합칩니다.
  • 성향 분석은 기본 무료(단어 사전). 필요할 때만 💰 Claude AI 로 추가 분석(API 키 필요, 비용 듦).
  • 데일리 DB · 대시보드: 보고일마다 쌓이고, 메일에 그대로 붙여 넣는 보고용 대시보드를 복사할 수 있습니다.

2. 설치 (처음 한 번만)

① 압축 풀기

  1. 받은 압축 파일을 풀고, 그 안의 GV90수집기_확장프로그램 폴더를 지우지 않을 곳(예: 문서 폴더)에 둡니다.
    크롬은 이 폴더를 계속 읽으므로, 나중에 지우거나 옮기면 확장프로그램이 사라집니다.

② 크롬에 올리기

  1. 크롬 주소창에 chrome://extensions → Enter.
  2. 오른쪽 위 개발자 모드 켜기 → 왼쪽 위 압축해제된 확장 프로그램을 로드합니다.
  3. GV90수집기_확장프로그램 폴더를 고르면 GV90 그림의 「GV90(JG1) 온라인 게시물 일일 수집」 카드가 생깁니다.
  4. 퍼즐 모양 아이콘 → 「GV90(JG1) 온라인 게시물 일일 수집」 옆 핀(📌)으로 고정하면 편합니다.

③ 네이버 로그인

동호회(카페)를 수집하려면 크롬에서 네이버에 로그인해 둡니다. 언론·유튜브·커뮤니티는 로그인 없이 수집됩니다.

새 버전으로 바꿀 때: 확장을 삭제하지 말고 쓰던 폴더에 새 파일을 덮어쓴 뒤 chrome://extensions 에서 새로고침(↻)하세요. 삭제하면 데일리 DB 가 지워집니다(지우기 전에 데일리 DB 의 💾 백업 받기).

3. 매일 사용

① 게시물 수집 (자동이면 저절로)

  1. 아이콘을 누르면 🔍 게시물 수집 화면이 열립니다. 수집 기간은 기본값(근무일엔 직전 근무일 07:30 ~ 금일 07:30)으로 맞춰져 있습니다.
  2. 수집 시작 → 채널마다 기간 안의 GV90 관련 글을 찾고, 글을 열어 본문·조회수·댓글 수를 확인한 뒤 무료 성향 분석을 합니다.
  3. 근무일에는 아직 엑셀에 담지 않은 휴일 수집분이 결과 표에 자동으로 합쳐집니다.

② 결과 확인

  • URL 앞 👁 조회 💬 댓글 뱃지: 조회 1,000 이상 · 댓글 20개 이상 · 🔥 강한 비판이면 빨간색.
  • 필요 없는 글은 체크를 풀고, 주요 내용 · 구분 · 성향은 표에서 바로 고칩니다(고친 값은 다시 분석해도 그대로).
  • 더 정확히 하려면 💰 Claude AI 로 추가 분석 (설정에 API 키 · 실행 전 예상 비용 표시).

③ 엑셀 만들기

엑셀 만들기 (데일리 DB 저장) → 데일리 DB 에 저장하고, 엑셀(YYMMDD_GV90 온라인 동향 raw data.xlsx)을 저장 폴더에 바로 저장합니다(딩동댕 🎵 · 받기 버튼 무지개 효과). 기본은 데일리 DB 전체 누적(연번 이어짐), '이번 보고분만'도 고를 수 있습니다.

④ 댓글 수집 (필요할 때)

  1. 💬 댓글 수집 탭(또는 엑셀을 만든 뒤 💬 이 게시글들 댓글 수집하러 가기 →)에서 데일리 DB 의 게시글을 고릅니다 (기본: 최근 보고일 · 댓글 있는 글).
  2. 체크한 글 댓글 수집 → 언론(네이버 뉴스 댓글·답글) · 동호회(카페 글을 사람처럼 천천히 열어 읽음 · 안 보이면 네이버 검색 경유) · 유튜브(댓글·답글) · 커뮤니티(화면 → 탭 '더보기'까지, 뽐뿌는 댓글 목록 전체읽기로 1쪽부터 끝까지). 삭제·블라인드·차단 댓글은 뺍니다.
  3. 댓글 성향은 무료 분석이 기본이고, 표에서 바로 고치거나 💰 Claude AI 로 댓글 성향 추가 분석을 할 수 있습니다.
  4. 댓글은 데일리 DB 에 바로 저장되어 게시물 엑셀의 '댓글' 시트 · 대시보드(반응 = 게시글 + 댓글)에 들어갑니다. 댓글 엑셀 만들기로 YYMMDD_GV90 온라인 동향 댓글 raw data.xlsx(댓글 · 게시글별 댓글 성향)도 받습니다.
  5. 못 읽은 글은 수집 전·0개·실패 글만 선택 → 다시 수집. 다시 모아도 같은 댓글은 늘지 않고, 직접 고친 성향은 그대로입니다.

4. 자동 수집 · 휴일

  • 매일 06:00(⚙ 설정에서 변경)에 수집 화면이 열려 수집 → 분석 → (근무일이면) 엑셀 저장까지 하고 알림을 띄웁니다. PC·크롬이 켜져 있고 네이버에 로그인돼 있어야 합니다.
  • 그 시각에 PC 가 꺼져 있었으면 그날 정오 전에 크롬을 켤 때 시작합니다.
  • 휴일(주말·공휴일·회사 휴무)엔 수집만 해 데일리 DB 에 두고, 다음 근무일 아침 엑셀에 합칩니다. 공휴일·회사 휴무일은 설정의 휴일 목록에서 고칩니다(음력 공휴일·대체공휴일은 정부 발표로 확인).

5. 데일리 DB · 대시보드

  • 🗄 데일리 DB: 보고일별 건수(전일 대비 ▲/▼) · 채널 · 성향, 그날 엑셀 다시 받기, 엑셀에서 고친 파일 수정본 올리기, 기존 raw data 엑셀 등록(차종 GV90·JG 행), 기간 엑셀, 백업.
  • 📊 대시보드: 맨 위 보고용 대시보드는 📋 메일에 붙여넣기용 복사 → 메일 본문에 붙여 넣기. 붙여 넣기가 안 되면 '이미지 없이 복사' 또는 'HTML 코드로 복사'. 요약 두 줄은 눌러서 고칠 수 있습니다. 아래 상세 대시보드에서 보고일별 성향 막대·채널·구분·커뮤니티·주목 게시물을 봅니다.

6. 저장 위치 · 알림음 (⚙ 설정)

  • 📁 저장 폴더 고르기: 고른 폴더에 바로 저장(크롬을 새로 켠 뒤 처음 저장할 때 허락을 한 번 물을 수 있음). 고르지 않으면 크롬 다운로드 폴더(하위 폴더 지정 · 매번 묻기 가능).
  • 끝나면 '딩동댕' 알림음 (끄기 가능).
네이버 카페는 계정 보호를 위해 API 를 부르지 않고 화면을 하나씩 열어 사람처럼 천천히 읽습니다. 보호조치·로그인 풀림이 보이면 바로 멈춥니다. 그래도 자동 수집은 이용약관상 제한될 수 있으니 수집 속도는 '보통' 이하로 쓰세요.
