3. 확장프로그램 설치 (처음 한 번만)

① 압축 풀기

  1. 유튜브추출기_윈도우용.zip 파일을 마우스 오른쪽 클릭 → [압축 풀기] 또는 [모두 압축 풀기].
  2. 압축을 푼 유튜브추출기_윈도우용 폴더를 지우지 않을 곳(예: 문서 폴더)으로 옮겨 둡니다.
    크롬은 이 폴더를 계속 읽으므로, 나중에 지우거나 옮기면 확장프로그램이 사라집니다.

② 크롬에 확장프로그램 올리기

  1. 크롬 주소창에 chrome://extensions 입력 → Enter.
  2. 오른쪽 위 개발자 모드 스위치를 켭니다.
  3. 왼쪽 위 압축해제된 확장 프로그램을 로드합니다 → 유튜브추출기_확장프로그램 폴더를 선택 → 폴더 선택.
  4. 「YouTube 스크립트 및 영상 파일 추출」 카드가 생기면 성공입니다.
  5. 퍼즐 모양 아이콘 → 「YouTube 스크립트 및 영상 파일 추출」 옆 핀(📌)을 눌러 고정합니다.
크롬을 켤 때 “개발자 모드 확장 프로그램 사용 중지” 안내가 뜨면 [X] 또는 [닫기]를 누르세요.

4. 빠른 다운로드 도우미 설치 (처음 한 번만)

크롬 확장프로그램은 보안상 PC 프로그램을 직접 실행할 수 없어서, 영상을 재생 없이 바로 받으려면 도우미를 한 번 설치합니다. (관리자 권한은 필요 없고, 내 계정에만 설치됩니다)

  1. 유튜브추출기_윈도우용 폴더의 빠른다운로드_도우미설치.bat을 더블클릭합니다.
  2. 파란 “Windows의 PC 보호” 창이 뜨면 [추가 정보] → [실행]을 누릅니다. (인터넷에서 받은 파일이라 처음 한 번 나오는 안내입니다)
  3. 검은 창이 열리고 유튜브 다운로드 도구(yt-dlp, Deno, ffmpeg, 약 200MB)를 내려받습니다. 몇 분 동안 창을 닫지 말고 기다리세요.
  4. “설치를 마쳤습니다” 창이 뜨면 확인을 누릅니다.
  5. 확장프로그램의 영상·음성 파일 다운로드 화면이 열려 있었다면 새로고침(F5)합니다.
크롬·엣지·웨일·브레이브에 모두 등록되므로 어느 브라우저에서든 쓸 수 있습니다. 도우미는 사흘마다 유튜브 다운로드 도구를 저절로 최신으로 바꿉니다. 그래도 받지 못하는 영상이 생기면 설치 파일을 한 번 더 실행하세요.

5. 사용 방법

영상·음성 파일 받기

  1. 확장 아이콘 → 위쪽 메뉴에서 영상·음성 파일 다운로드.
  2. 저장 형식: 영상 빠른 다운로드(기본) 또는 음성 빠른 다운로드. → “✔ 윈도우 도우미가 연결되었습니다”가 보이면 준비 완료입니다.
  3. 영상은 화질을 고릅니다: 360p / 480p(기본) / 720p / 1080p. (10분 영상 기준 480p 약 30~60MB, 1080p 약 120~250MB)
  4. 유튜브 URL을 한 줄에 하나씩 붙여넣고 다운로드.
  5. 다운로드 폴더에 20261010_유튜브제목.mp4(영상) / .mp3(음성)로 저장됩니다.

스크립트 만들기

  1. 확장 아이콘 → 위쪽 메뉴에서 스크립트 추출.
  2. 유튜브 URL을 넣고 인식 방식을 고릅니다.
    • 유튜브 스크립트 가져오기(기본, 추천): 영상 설명란의 …더보기 → 스크립트 표시를 눌러 오른쪽에 나오는 스크립트를 그대로 가져옵니다. 영상을 재생하지 않아 영상 하나에 몇 초면 끝나고 가장 정확합니다.
      스크립트가 없는 영상은 줄 오른쪽에 화면 자막으로 음성으로 버튼이 나오니 골라 누르세요. “스크립트가 없을 때”를 화면 자막 인식으로 자동 수집 / 음성 인식으로 자동 수집으로 바꾸면 버튼을 누르지 않아도 알아서 넘어갑니다. 스크립트가 있는데 실패한 경우는 재시도를 누르세요.
    • 화면 자막 인식: 화면 아래 가운데 자막 글자를 읽습니다. 3배속으로 재생해 영상 길이의 약 1/3 시간이 걸립니다. 자막이 더 위에 있으면 “자막 위치”를 1/3로 바꾸세요.
    • 음성 인식: 들리는 말을 받아씁니다. 영상 길이만큼 걸리고, 처음 한 번 음성인식 모델(300MB~1.5GB)을 내려받습니다.
  3. 스크립트 만들기를 누릅니다.
    • 유튜브 스크립트 가져오기는 탭이나 창을 하나도 띄우지 않습니다. 다른 작업을 하고 있어도 방해하지 않습니다. 끝까지 받지 못한 영상은 줄 오른쪽 화면에서 가져오기를 누르면, 그때만 유튜브 탭을 잠깐 띄워 ‘…더보기 → 스크립트 표시’를 직접 눌러 가져옵니다.
    • 화면 자막 인식·음성 인식은 영상을 실제로 재생해야 해서 유튜브 탭이 앞에 열립니다. 진행 중에는 그 탭을 닫거나 영상을 멈추지 마세요.
  4. 진행 목록의 영상 주소를 누르면 그 영상이 새 탭으로 열립니다.
  5. 모두 끝나면 “스크립트 수집을 마쳤습니다” 알림이 뜹니다. 파일은 자동으로 내려받지 않습니다.
    • 전체 스크립트 한 파일로 받기 (.txt): 모든 영상의 스크립트(교정본)를 ==== 구분선과 [1/3] 영상 제목, 영상 주소로 나눠 파일 하나(20261010_유튜브스크립트_3개.txt)로 받습니다. 영상별로 골라 복사해 붙이기 쉽습니다.
    • 줄 오른쪽 보기 복사 .txt: 그 영상만 보거나, 클립보드에 복사하거나, 파일로 받습니다(.txt 는 교정본 + _원본.txt 두 파일).
    • 수집하지 못한 영상이 있으면 수집 안 된 영상 전체 다시 수집으로 한꺼번에 다시 수집하거나, 줄마다 재시도 / 화면에서 가져오기를 누르세요. 스크립트가 없는 영상은 화면 자막으로 음성으로 버튼으로 다른 방식으로 만들 수 있습니다.
  6. 교정본은 띄어쓰기·자주 틀리는 맞춤법을 기본 규칙으로 고친 것입니다(예: 됬어요→됐어요, 할수있다→할 수 있다, 그런것같아요→그런 것 같아요). 이 PC 안에서 규칙으로만 고치고(외부로 보내지 않음) 확실히 틀린 경우만 고치니, 문맥에 따른 띄어쓰기까지는 한 번 훑어보세요.
자동 인식 결과라 고유명사·전문용어 등은 틀릴 수 있으니 한 번 훑어보고 고쳐 쓰세요. 인식은 모두 이 PC 안에서 처리하며 영상 소리·화면을 외부로 보내지 않습니다.

6. 문제가 생기면

증상해결
“윈도우 도우미가 설치되어 있지 않습니다”4번(도우미 설치)을 진행하고 화면을 새로고침(F5)합니다. 설치 후에도 같으면 크롬을 완전히 껐다 켭니다.
백신 프로그램이 경고함yt-dlp 같은 다운로드 도구를 경고하는 경우가 있습니다. 공식 배포처(GitHub)에서 받은 파일입니다. 회사 보안 정책이 있다면 담당자와 상의하세요.
“받지 못함: …” 오류비공개·연령 제한·삭제된 영상일 수 있습니다. 계속 실패하면 빠른다운로드_도우미설치.bat을 다시 실행해 도구를 최신으로 바꾸세요.
도우미를 지우고 싶을 때빠른다운로드_도우미제거.bat을 더블클릭합니다.
새 버전으로 바꾸고 싶을 때새 압축 파일의 폴더로 바꾸고, chrome://extensions에서 카드의 새로고침(↻)을 누릅니다. 도우미 설치 파일도 한 번 다시 실행하세요.

받은 영상·음성의 저작권은 영상 주인에게 있습니다. 개인 보관·업무 참고 용도로만 쓰고 다시 올리거나 배포하지 마세요.
