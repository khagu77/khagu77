팰리세이드 전동시트 게시물·댓글 수집기 설치·사용 안내서 (윈도우)

크롬 확장프로그램 「팰리세이드(LX3) 전동 시트 관련 카페·유튜브 게시물 및 댓글 수집기」 · 동호회 관련 게시물 찾기 + 네이버 카페 / 유튜브 댓글을 raw data 엑셀에 정리

1. 무엇을 하나요?

  • LX3 팰리세이드 전동 시트 관련 메뉴: 동호회 12곳에서 '시트'로 검색해 정한 시간(기본 직전 근무일 오후 12시 ~ 오늘 오후 12시, 주말·공휴일 자동 반영)에 올라온 전동시트 끼임·폴딩·사망·리콜 관련 글을 추려 '채널별 버즈량 현황' 엑셀로 받고, 그 글들과 저장해 둔 유튜브 영상의 댓글 수집으로 바로 넘깁니다.
  • 댓글 수집 메뉴: 네이버 카페 게시글, 유튜브 영상 URL을 넣으면 댓글·답글을 모아 엑셀(.xlsx)로 저장합니다.
  • 기존 raw data 엑셀을 고르면 동호회 시트에 이어 쓰고, 유튜브 시트는 그날 수집한 내용으로 교체합니다.
  • 파이썬이나 다른 프로그램을 설치할 필요가 없습니다. 크롬만 있으면 됩니다.

3. 설치 (처음 한 번만)

① 압축 풀기

  1. 댓글수집기_윈도우용.zip 파일을 마우스 오른쪽 클릭 → [압축 풀기] 또는 [모두 압축 풀기]를 누릅니다.
  2. 압축을 푼 댓글수집기_윈도우용 폴더를 지우지 않을 곳(예: 문서 폴더)으로 옮겨 둡니다.
    크롬은 이 폴더를 계속 읽으므로, 나중에 지우거나 옮기면 확장프로그램이 사라집니다.

② 크롬에 확장프로그램 올리기

  1. 크롬 주소창에 chrome://extensions 를 입력하고 Enter.
  2. 오른쪽 위 개발자 모드 스위치를 켭니다.
  3. 왼쪽 위 압축해제된 확장 프로그램을 로드합니다 버튼을 누릅니다.
  4. 댓글수집기_윈도우용 폴더 안의 댓글수집기_확장프로그램 폴더를 선택하고 폴더 선택.
  5. 팰리세이드 그림의 「팰리세이드(LX3) 전동 시트 관련 카페·유튜브 게시물 및 댓글 수집기」 카드가 생기면 성공입니다.
  6. 크롬 오른쪽 위 퍼즐 모양 아이콘 → 「팰리세이드(LX3) 전동 시트 관련 카페·유튜브 게시물 및 댓글 수집기」 옆 핀(📌)을 눌러 고정하면 편합니다.
크롬을 켤 때 “개발자 모드 확장 프로그램 사용 중지” 안내가 뜰 수 있습니다. 직접 올린 확장이라 나오는 안내이니 [X] 또는 [닫기]를 누르면 됩니다. (“사용 중지”를 누르면 확장이 꺼집니다)

4. 매일 사용하는 방법 ① LX3 팰리세이드 전동 시트 관련

  1. 크롬에서 네이버에 로그인해 둡니다.
  2. 크롬 오른쪽 위 팰리세이드 아이콘을 누르면 LX3 팰리세이드 전동 시트 관련 화면이 열립니다(위쪽 메뉴로 댓글 수집 화면과 오갑니다).
  3. 시간은 화면을 열 때마다 직전 근무일 오후 12시 ~ 오늘 오후 12시로 맞춰집니다(월요일은 금요일 12시부터, 연휴·대체공휴일 다음 날은 연휴 전 마지막 근무일 12시부터 · 임시공휴일·회사 휴무는 설정의 ‘추가 휴일’에). 필요하면 바꾸고, 게시물 찾기를 누릅니다.
    → 동호회 12곳의 검색 화면을 탭으로 하나씩 열어(잠깐 열렸다 닫힘) '시트' 검색 결과를 읽습니다. 몇 분 걸립니다.
    → 목록에 날짜만 보이는 어제 글은 정확한 시간을 확인하려고 글을 한 번 더 열어 봅니다.
  4. 결과 표에서 관련 단어(전동시트·끼임·폴딩·사망·리콜·원터치·업데이트 등)가 있는 글은 체크되어 있고, 없는 글은 흐리게 체크가 풀려 있습니다. 필요 없는 글은 [삭제]하거나 체크를 풀고, 필요한 글은 체크합니다. 제목을 누르면 글이 새 탭으로 열립니다.
    표 위의 모두 선택 모두 해제 선택 반전 선택 삭제로 한꺼번에 고를 수 있습니다(예: 필요 없는 글만 체크 → 선택 삭제 → 모두 선택). 지운 결과는 화면을 다시 열어도 남아 있습니다.
  5. 기존 엑셀 파일에서 가장 최근의 '채널별 버즈량 현황' 파일을 고르면 마지막 순번 다음부터 이어 쓰고(파일에 이미 있는 글은 체크가 풀림), 고르지 않으면 같은 양식의 새 파일로 받습니다. 엑셀 받기 → 파일명 앞 날짜만 오늘로 바뀐 파일이 저장됩니다. 기존 파일을 첨부하지 않았으면 “첨부 없이 진행할지” 먼저 묻습니다([취소]를 누르면 파일 고르기 창이 열림).
  6. 체크한 글 댓글 수집하기를 누르면 그 글들(과 ‘유튜브 목록도 함께’를 켰으면 저장해 둔 유튜브 영상)이 댓글 수집 화면에 들어갑니다. raw data 파일을 고르고 수집 시작.
엑셀 열들어가는 값
순번 · 채널마지막 순번 다음 번호 · 동호회
매체명카페 제목(페이지 소스의 <title>)에서 뒤의 : 네이버 카페를 뺀 이름 (예: 현대 아이오닉9 오너스 - 나이너스)
게시일 · 제목글 작성 날짜·시간 · 글 제목
URL항상 https://cafe.naver.com/카페주소/글번호 형식 (예: https://cafe.naver.com/allfm01/2157343)
  • 순서: 날짜순 → 동호회 목록 순(같은 날짜 안에서는 설정의 동호회 순서대로).
  • 유튜브 영상 목록: 매일 댓글을 모을 영상 주소를 추가·삭제해 두면 이 PC 크롬에 저장됩니다. 유튜브 목록 댓글 수집하기로 바로 댓글 수집 화면에 넘깁니다.
  • 동호회 목록 · 관련 단어 설정(화면의 접힌 칸): 동호회 주소, 관련 글 단어 / 관련 없는 글 단어, 카페마다 볼 페이지 수를 바꿀 수 있습니다. 동호회 명과 영문 카페 주소(예: allfm01)는 자동으로 채워지며, 비어 있으면 직접 넣을 수 있습니다.
  • 엑셀 저장 위치(설정 칸): 크롬 다운로드 폴더 안의 폴더 이름(예: 팰리세이드 모니터링/일일보고)을 넣으면 두 화면의 엑셀이 모두 그 폴더에 저장됩니다. 다운로드 폴더 밖(예: 바탕화면)에 저장하려면 ‘받을 때마다 저장 위치 묻기’를 켜고 직접 고르세요(크롬은 확장프로그램이 다운로드 폴더 밖을 직접 정하지 못하게 되어 있습니다).
  • 검색이 잘 안 되면(네이버 화면이 바뀐 경우) 카페에서 '시트'로 직접 검색한 뒤 주소창의 주소를 그대로 ‘카페 검색 주소 형식’ 칸에 붙여 넣으세요.

5. 매일 사용하는 방법 ② 댓글 수집

  1. (네이버 카페를 수집하는 날) 크롬에서 네이버에 로그인해 둡니다. 유튜브만 수집할 때는 필요 없습니다.
  2. 위쪽 메뉴의 댓글 수집을 누릅니다(LX3 화면에서 넘어온 경우 URL이 이미 들어 있습니다).
  3. 기존 엑셀 파일에서 가장 최근에 받은 raw data 파일(예: 20261008_…raw_data….xlsx)을 고릅니다.
    → “동호회 ○○행(마지막 연번 ○○) 다음부터 이어 씁니다”라고 나오면 정상입니다.
  4. 오늘 수집할 카페 글 / 유튜브 영상 URL을 한 줄에 하나씩 붙여넣습니다. (섞어서 넣어도 되고, naver.me 짧은 주소도 엑셀에는 https://cafe.naver.com/카페주소/글번호로 들어갑니다)
  5. 수집 시작을 누르고 기다립니다. 진행 상황이 표로 보입니다.
  6. 끝나면 다운로드 폴더에 파일명 앞 날짜만 오늘로 바뀐 엑셀(예: 20261010_…raw_data….xlsx)이 저장됩니다.

엑셀에 들어가는 방식

시트처리
동호회네이버 카페 댓글을 기존 마지막 연번 다음부터 이어서 추가합니다. 파일에 이미 있는 댓글(같은 글·작성일·내용)과 삭제된 댓글은 넣지 않습니다.
유튜브그날 입력한 영상들의 댓글로 시트 전체를 교체합니다(입력 순서대로, 연번 1부터). 수집에 실패한 영상은 기존 댓글을 남깁니다. 유튜브 URL을 넣지 않은 날은 그대로 둡니다.
언론, 자동차 커뮤니티손대지 않습니다 (서식·링크 그대로).
  • 열 구성: 연번 / 채널 / 작성일 / 댓글 / url
  • 작성일: 카페는 2026.10.08. 10:44, 유튜브는 6개월 전, 9일 전(수정됨)처럼 유튜브 표시 그대로
  • 기존 엑셀을 고르지 않으면 같은 양식(4개 시트)의 새 파일에 그날 수집한 댓글만 담아 저장합니다.

최종 DB (매일 파일 고르기 없이 이어 쓰기)

  1. 처음 한 번: 위쪽 메뉴 최종 DB → 게시물 리스트·댓글 raw data 칸의 파일 등록으로 지금까지의 최종 파일을 넣습니다(파일명 앞 날짜로 등록).
  2. 그다음부터는 게시물 찾기·댓글 수집에서 파일을 고르지 않아도 가장 최근(최종) 파일의 마지막 순번·연번 다음에 이어 쓰고, 받은 파일은 오늘 날짜의 최종 파일로 자동 저장됩니다(같은 날 다시 받으면 그날 파일을 바꿈).
  3. 엑셀에서 직접 고쳤다면 최종 DB에서 그 날짜의 수정본 올리기를 누르세요. 다음 수집은 고친 파일에 이어 씁니다.
  4. 따로 만들고 싶을 때는 ‘별도 파일로 작성’을 체크하세요(새 파일·최종 DB 저장 안 함). 다른 파일에 이어 쓰려면 ‘기존 엑셀 파일’에서 직접 고르면 됩니다.
  5. 받은 엑셀은 열면 커서가 마지막 행 바로 아래에 있고, 그 위 내용이 보이게 열립니다.
  6. 최종 DB 는 이 PC 크롬에 저장됩니다(확장프로그램을 삭제하면 함께 지워지니, 삭제 전에 [받기]로 내려받아 두세요).

6. 네이버 계정 보호를 위해 꼭 지켜 주세요

  • 카페 글은 사람이 보는 것처럼 탭으로 하나씩 열어 천천히 읽습니다(글 하나에 10~20초, 수집 중 탭이 잠깐 열렸다 닫힘).
  • 한 번에 30개 이하로 나누고, 시간 간격을 두고 수집하세요. 30개가 넘으면 확인 창이 뜹니다.
  • 그래도 네이버가 자동 수집으로 판단하면 “회원님의 아이디를 보호하고 있습니다” 화면이 뜰 수 있습니다.
    → 수집을 멈추고 [보호조치 해제] → 본인 확인 → 비밀번호 변경 후, 며칠 쉬었다가 사용하세요.

7. 문제가 생기면

증상해결
“네이버 로그인이 필요합니다”크롬에서 네이버에 로그인한 뒤 다시 수집합니다.
“댓글 영역을 찾지 못함”가입하지 않은 카페의 멤버 공개 글, 삭제된 글, 댓글을 막은 글일 수 있습니다. 크롬에서 직접 열어 보이는지 확인하세요.
게시물 찾기에서 “검색 결과 없음” / “글 목록을 읽지 못함”만 나옴찾기가 끝나면 나오는 진단 파일 받기를 눌러 받은 …_LX3_진단.json 파일을 개발자에게 보내 주세요(화면 구조를 보고 맞춰 고칩니다). 설정의 ‘카페 검색 주소 형식’에 카페에서 직접 검색한 주소를 붙여 넣어 보는 것도 방법입니다.
URL이 …/f-e/cafes/…/articles/… 긴 주소로 나옴그 카페의 영문 주소를 아직 모르는 경우입니다. 설정 표의 ‘영문 카페 주소’ 칸에 카페 주소(예: allfm01)를 넣으면 바로 짧은 주소로 바뀝니다.
1.2.2 로 바꿀 때chrome://extensions에서 예전 카드를 삭제한 뒤 새 댓글수집기_확장프로그램 폴더를 다시 올려 주세요. 이번 버전부터 확장 고유번호가 고정되어, 다음 업데이트부터는 폴더만 바꾸고 새로고침(↻)해도 유튜브 목록·설정이 그대로 남습니다.
엑셀 파일이 안 보임크롬 오른쪽 위 다운로드 아이콘(↓) 또는 파일 탐색기 → 다운로드 폴더를 확인하세요.
새 버전으로 바꾸고 싶을 때새 압축 파일의 댓글수집기_확장프로그램 폴더로 기존 폴더를 바꾸고, chrome://extensions에서 카드의 새로고침(↻)을 누릅니다.

수집한 닉네임·댓글은 개인정보일 수 있으니 네이버 이용약관과 개인정보보호법을 지켜 업무 용도로만 사용하세요.
