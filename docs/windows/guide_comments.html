댓글수집기 설치·사용 안내서 (윈도우)

크롬 확장프로그램 「카페·유튜브 댓글 수집기」 · 네이버 카페 / 유튜브 댓글을 raw data 엑셀에 정리

1. 무엇을 하나요?

  • 네이버 카페 게시글, 유튜브 영상 URL을 넣으면 댓글·답글을 모아 엑셀(.xlsx)로 저장합니다.
  • 기존 raw data 엑셀을 고르면 동호회 시트에 이어 쓰고, 유튜브 시트는 그날 수집한 내용으로 교체합니다.
  • 파이썬이나 다른 프로그램을 설치할 필요가 없습니다. 크롬만 있으면 됩니다.

2. 압축 파일 안의 내용

압축을 풀면 댓글수집기_윈도우용 폴더 안에 아래 파일이 있습니다.

이름설명
댓글수집기_확장프로그램크롬에 올릴 폴더 (지우거나 옮기지 마세요)
설치안내서_댓글수집기.pdf지금 보고 있는 안내서

3. 설치 (처음 한 번만)

① 압축 풀기

  1. 댓글수집기_윈도우용.zip 파일을 마우스 오른쪽 클릭 → [압축 풀기] 또는 [모두 압축 풀기]를 누릅니다.
  2. 압축을 푼 댓글수집기_윈도우용 폴더를 지우지 않을 곳(예: 문서 폴더)으로 옮겨 둡니다.
    크롬은 이 폴더를 계속 읽으므로, 나중에 지우거나 옮기면 확장프로그램이 사라집니다.

② 크롬에 확장프로그램 올리기

  1. 크롬 주소창에 chrome://extensions 를 입력하고 Enter.
  2. 오른쪽 위 개발자 모드 스위치를 켭니다.
  3. 왼쪽 위 압축해제된 확장 프로그램을 로드합니다 버튼을 누릅니다.
  4. 댓글수집기_윈도우용 폴더 안의 댓글수집기_확장프로그램 폴더를 선택하고 폴더 선택.
  5. 「카페·유튜브 댓글 수집기」 카드가 생기면 성공입니다.
  6. 크롬 오른쪽 위 퍼즐 모양 아이콘 → 「카페·유튜브 댓글 수집기」 옆 핀(📌)을 눌러 고정하면 편합니다.
크롬을 켤 때 “개발자 모드 확장 프로그램 사용 중지” 안내가 뜰 수 있습니다. 직접 올린 확장이라 나오는 안내이니 [X] 또는 [닫기]를 누르면 됩니다. (“사용 중지”를 누르면 확장이 꺼집니다)

4. 매일 사용하는 방법

  1. (네이버 카페를 수집하는 날) 크롬에서 네이버에 로그인해 둡니다. 유튜브만 수집할 때는 필요 없습니다.
  2. 크롬 오른쪽 위 확장 아이콘을 누르면 수집 화면이 새 탭으로 열립니다.
  3. 기존 엑셀 파일에서 가장 최근에 받은 raw data 파일(예: 20261008_…raw_data….xlsx)을 고릅니다.
    → “동호회 ○○행(마지막 연번 ○○) 다음부터 이어 씁니다”라고 나오면 정상입니다.
  4. 오늘 수집할 카페 글 / 유튜브 영상 URL을 한 줄에 하나씩 붙여넣습니다. (섞어서 넣어도 됩니다)
  5. 수집 시작을 누르고 기다립니다. 진행 상황이 표로 보입니다.
  6. 끝나면 다운로드 폴더에 파일명 앞 날짜만 오늘로 바뀐 엑셀(예: 20261010_…raw_data….xlsx)이 저장됩니다.

엑셀에 들어가는 방식

시트처리
동호회네이버 카페 댓글을 기존 마지막 연번 다음부터 이어서 추가합니다. 파일에 이미 있는 댓글(같은 글·작성일·내용)과 삭제된 댓글은 넣지 않습니다.
유튜브그날 입력한 영상들의 댓글로 시트 전체를 교체합니다(입력 순서대로, 연번 1부터). 수집에 실패한 영상은 기존 댓글을 남깁니다. 유튜브 URL을 넣지 않은 날은 그대로 둡니다.
언론, 자동차 커뮤니티손대지 않습니다 (서식·링크 그대로).
  • 열 구성: 연번 / 채널 / 작성일 / 댓글 / url
  • 작성일: 카페는 2026.10.08. 10:44, 유튜브는 6개월 전, 9일 전(수정됨)처럼 유튜브 표시 그대로
  • 기존 엑셀을 고르지 않으면 같은 양식(4개 시트)의 새 파일에 그날 수집한 댓글만 담아 저장합니다.

5. 네이버 계정 보호를 위해 꼭 지켜 주세요

  • 카페 글은 사람이 보는 것처럼 탭으로 하나씩 열어 천천히 읽습니다(글 하나에 10~20초, 수집 중 탭이 잠깐 열렸다 닫힘).
  • 한 번에 30개 이하로 나누고, 시간 간격을 두고 수집하세요. 30개가 넘으면 확인 창이 뜹니다.
  • 그래도 네이버가 자동 수집으로 판단하면 “회원님의 아이디를 보호하고 있습니다” 화면이 뜰 수 있습니다.
    → 수집을 멈추고 [보호조치 해제] → 본인 확인 → 비밀번호 변경 후, 며칠 쉬었다가 사용하세요.

6. 문제가 생기면

증상해결
“네이버 로그인이 필요합니다”크롬에서 네이버에 로그인한 뒤 다시 수집합니다.
“댓글 영역을 찾지 못함”가입하지 않은 카페의 멤버 공개 글, 삭제된 글, 댓글을 막은 글일 수 있습니다. 크롬에서 직접 열어 보이는지 확인하세요.
엑셀 파일이 안 보임크롬 오른쪽 위 다운로드 아이콘(↓) 또는 파일 탐색기 → 다운로드 폴더를 확인하세요.
새 버전으로 바꾸고 싶을 때새 압축 파일의 댓글수집기_확장프로그램 폴더로 기존 폴더를 바꾸고, chrome://extensions에서 카드의 새로고침(↻)을 누릅니다.

수집한 닉네임·댓글은 개인정보일 수 있으니 네이버 이용약관과 개인정보보호법을 지켜 업무 용도로만 사용하세요.
