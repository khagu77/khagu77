# 카페·유튜브 댓글 수집기

네이버 카페 게시글이나 유튜브 영상 URL을 넣으면 **댓글/답글을 모두 모아 엑셀(.xlsx)로 저장**합니다.

두 가지 방식이 있습니다.
- **크롬 확장프로그램 (추천)** — 터미널·파이썬 설치 없이 크롬에서 바로 사용. 네이버 카페 + 유튜브 지원.
- 파이썬 프로그램 — 터미널에서 실행. 네이버 카페만 지원. ⚠️ 자동화 브라우저 로그인 + API 반복 호출 방식이라 네이버 계정 보호조치가 걸릴 위험이 커서 **사용을 권장하지 않습니다.**

## 크롬 확장프로그램 (추천)

### 설치 (최초 1회)
1. 이 저장소를 ZIP으로 내려받아 압축을 풉니다.
   (https://github.com/khagu77/khagu77/archive/refs/heads/claude/kind-cerf-6qj9m7.zip)
2. 크롬 주소창에 `chrome://extensions` 를 입력해 들어갑니다.
3. 오른쪽 위 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다** 버튼을 누르고,
   압축 푼 폴더 안의 **`chrome-extension`** 폴더를 선택합니다.
5. 크롬 오른쪽 위 퍼즐 모양 아이콘 → **카페·유튜브 댓글 수집기** 옆 핀을 눌러 고정하면 편합니다.

> 압축 푼 폴더를 지우거나 옮기면 확장프로그램이 동작하지 않으니 그대로 두세요.

### 사용 (매일)
1. (네이버 카페를 수집할 때만) 크롬에서 네이버에 로그인해 둡니다.
2. 확장 아이콘을 누르면 수집 화면이 새 탭으로 열립니다.
3. **기존 엑셀 파일**에 가장 최근에 받은 raw data 파일(예: `20261008_…_raw_data_….xlsx`)을 선택합니다.
4. 오늘 수집할 카페 글 / 유튜브 영상 URL을 한 줄에 하나씩 붙여넣고 **수집 시작**.
5. 끝나면 **파일명 앞 날짜만 오늘 날짜로 바뀐 파일**(예: `20261010_…_raw_data_….xlsx`)이 다운로드 폴더에 저장됩니다.

### 네이버 계정 보호를 위한 동작
- 네이버 카페는 API 를 직접 부르지 않고, **게시글을 백그라운드 탭으로 열어 화면에 보이는 댓글을 읽습니다.** (수집 중 탭이 잠깐 열렸다 닫힙니다)
- 글과 글 사이 4~8초, 댓글 페이지 사이 2~4초를 무작위로 기다립니다. 글 하나에 10~20초 정도 걸립니다.
- 카페 글을 한 번에 30개보다 많이 넣으면 확인 창이 뜹니다. 가능하면 나눠서, 시간 간격을 두고 수집하세요.
- 그래도 자동 수집은 네이버 이용약관상 제한될 수 있고 보호조치가 다시 걸릴 수 있습니다. 걸리면 수집을 멈추고 보호조치 해제(본인 확인 + 비밀번호 변경) 후 며칠 쉬세요.

### 엑셀에 들어가는 방식
| 시트 | 처리 |
|---|---|
| 동호회 | 네이버 카페 댓글을 **기존 마지막 연번 다음부터 이어서** 추가. 파일에 이미 있는 댓글(같은 글·작성일·내용)은 다시 넣지 않음. 삭제된 댓글 제외 |
| 유튜브 | **그날 입력한 영상들의 댓글로 시트 전체를 교체** (입력 순서대로, 연번 1부터). 수집에 실패한 영상은 파일에 있던 그 영상의 기존 행을 남김. 그날 유튜브 URL을 하나도 넣지 않으면 유튜브 시트는 그대로 둠 |
| 언론, 자동차 커뮤니티 | 손대지 않음 (서식·링크 포함 그대로) |

- 열 구성은 기존 양식 그대로: `연번 / 채널 / 작성일 / 댓글 / url`
- 카페 작성일은 `2026.10.08. 10:44`, 유튜브 작성일은 `6개월 전`, `9일 전(수정됨)`처럼 유튜브 표시 그대로 들어갑니다.
- 카페 url 은 `https://cafe.naver.com/카페주소/글번호`, 유튜브 url 은 `https://www.youtube.com/watch?v=영상ID` 형식으로 통일됩니다.
- 새로 추가된 행은 바로 위 행의 서식(글꼴·행 높이 등)을 따라갑니다.
- 기존 파일을 선택하지 않으면 같은 양식(4개 시트)의 새 파일에 그날 수집한 댓글만 담아 저장합니다.
- 유튜브 지원 주소: `youtube.com/watch?v=…`, `youtu.be/…`, `youtube.com/shorts/…`, `youtube.com/live/…`
- 영상·댓글이 많으면 시간이 걸립니다. 중간에 **중지**를 누르면 그때까지 모은 내용으로 저장됩니다.

## 파이썬 프로그램 (네이버 카페 전용)

### 설치 (최초 1회)

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
python -m playwright install chromium
```

### 사용법

#### 가장 쉬운 방법 (대화형)

```bash
python naver_cafe_comments.py
```
Windows에서는 `run.bat`을 더블클릭해도 됩니다.

1. 로그인 세션이 없으면 브라우저 창이 뜹니다 → 직접 네이버에 로그인하세요. (창은 로그인이 확인되면 자동으로 닫힙니다)
2. `URL>` 프롬프트에 게시글 URL을 한 줄씩 붙여넣고, 다 넣었으면 빈 줄에서 Enter.
3. 실행한 폴더에 `네이버카페_댓글_YYYYMMDD_HHMMSS.xlsx` 파일이 생성됩니다.

#### 명령어로 실행

```bash
# 로그인만 따로 (세션은 naver_profile 폴더에 저장되어 계속 재사용됨)
python naver_cafe_comments.py login

# URL 직접 지정
python naver_cafe_comments.py collect "https://cafe.naver.com/카페주소/12345" "https://cafe.naver.com/ca-fe/cafes/111/articles/222"

# URL 목록 파일(한 줄에 하나, #으로 시작하면 무시) + 저장 파일명 지정
python naver_cafe_comments.py collect -f urls.txt -o 결과.xlsx

# 수집 과정을 브라우저로 보고 싶을 때
python naver_cafe_comments.py collect -f urls.txt --show-browser
```

#### 지원하는 URL 형식
- `https://cafe.naver.com/카페주소/게시글번호`
- `https://cafe.naver.com/카페주소?iframe_url_utf8=...` (게시글 열었을 때 주소창 URL)
- `https://cafe.naver.com/ca-fe/cafes/카페ID/articles/게시글번호`
- `https://cafe.naver.com/f-e/cafes/카페ID/articles/게시글번호`
- `https://m.cafe.naver.com/...` (모바일)
- `https://cafe.naver.com/ArticleRead.nhn?clubid=...&articleid=...`

### 엑셀 결과

| 시트 | 내용 |
|---|---|
| **댓글** | 게시글URL, 카페ID, 게시글번호, 게시글제목, 게시글작성자, 순번, 구분(댓글/답글), 댓글ID, 부모댓글ID, 작성자닉네임, 작성자ID, 댓글내용, 작성일시, 삭제여부, 첨부(이미지/스티커) |
| **요약** | 게시글별 댓글 수, 수집 방식, 성공/실패 사유 |

### 동작 방식
1. 로그인한 브라우저 세션(쿠키)으로 네이버 카페의 댓글 API를 페이지 단위로 호출해 전체 댓글을 가져옵니다.
2. API가 막히거나 응답 형식이 바뀐 경우, 자동으로 게시글 화면을 열어 댓글 영역을 읽고 댓글 페이지를 넘기며 수집합니다. (이 방식은 작성자ID가 비어 있을 수 있습니다)

### 주의사항
- **본인이 열람 권한이 있는 글**(가입한 카페의 멤버 공개 글 등)만 수집됩니다.
- 서버 부담을 줄이기 위해 요청 사이에 0.5초 대기합니다(`REQUEST_DELAY`). 너무 짧게 바꾸면 차단될 수 있습니다.
- 수집한 닉네임·댓글 등은 개인정보가 포함될 수 있으니 네이버 이용약관과 카페 규칙, 개인정보보호법을 지켜 사용하세요.
- `naver_profile/` 폴더에는 로그인 정보가 들어 있으니 다른 사람과 공유하지 마세요. 로그아웃하려면 이 폴더를 지우면 됩니다.

### 테스트
```bash
pip install pytest
# 확장프로그램 통합 테스트까지 하려면 일반 Chromium 경로 지정
CHROMIUM_PATH=/path/to/chromium python -m pytest tests
```

## YouTube 스크립트 및 영상 파일 추출 (크롬 확장프로그램)

위 댓글 수집기와는 **별도의 확장프로그램**입니다 (`youtube-extension` 폴더).
확장 아이콘을 누르면 열리는 화면 위쪽 메뉴에서 두 기능을 고릅니다.

| 메뉴 | 하는 일 | 저장 파일 |
|---|---|---|
| 스크립트 추출 | 유튜브에 올라온 자막은 쓰지 않고 영상을 재생하며 스크립트를 새로 만듭니다. 인식 방식은 둘 중 고릅니다.<br>• **음성 인식** — 들리는 말을 받아씀 (영상 길이만큼 걸림)<br>• **화면 자막 인식** — 화면 아래 가운데에 나오는 자막 글자를 읽음 (3배속 기준 영상 길이의 1/3 정도)<br>화면 출력칸에도 표시되어 **복사** 버튼으로 바로 붙여넣을 수 있습니다. | `20261010_유튜브제목.txt` (메모장용, 한 줄에 `00:00 스크립트 내용`) |
| 영상·음성 파일 다운로드 | 영상을 처음부터 끝까지 재생하며 화면·소리를 녹화하거나(영상), 소리만 녹음합니다(음성). 광고 구간은 빠집니다. | `20261010_유튜브제목.mp4` 또는 `20261010_유튜브제목.mp3` |

### 설치 (최초 1회)
1. 이 저장소를 ZIP으로 내려받아 압축을 풉니다.
   (https://github.com/khagu77/khagu77/archive/refs/heads/claude/awesome-darwin-opkdg0.zip)
2. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램을 로드합니다** → 압축 푼 폴더 안의 **`youtube-extension`** 폴더 선택.
4. 퍼즐 아이콘 → **YouTube 스크립트 및 영상 파일 추출** 옆 핀을 눌러 고정합니다.

### 사용
1. 확장 아이콘을 누르고 메뉴(스크립트 추출 / 영상·음성 파일 다운로드)를 고릅니다.
   영상·음성 파일 다운로드에서는 "저장 형식"에서 영상(.mp4) 또는 음성(.mp3)을 고릅니다.
2. 유튜브 URL을 한 줄에 하나씩 붙여넣고 시작 버튼을 누릅니다.
3. 유튜브 탭이 열려 영상이 처음부터 재생됩니다. **영상 길이만큼 시간이 걸리며**, 끝나면 탭이 닫히고 다운로드 폴더에 파일이 저장됩니다.
   진행 중에는 그 유튜브 탭을 닫거나 영상을 멈추지 마세요. (다른 탭에서 다른 일은 해도 됩니다)

- 스크립트 추출은 처음 한 번 음성인식 모델(Whisper)을 내려받습니다(300MB~1.5GB, 이후에는 저장된 것 사용).
  그래픽 가속(WebGPU)이 되는 PC는 가장 정확한 모델을 쓰고, 안 되면 CPU 로 처리합니다.
  처리는 모두 PC 안에서 하며 영상 소리를 외부로 보내지 않습니다.
- 화면 자막 인식은 **화면 아래 가운데의 자막(흰색·노란색 글자 + 테두리나 어두운 바탕)만** 읽습니다.
  영상 중간의 효과 글자, 댓글 인용 캡처, 사진 속 글자, 아래쪽 구석의 글자는 옮기지 않습니다.
  한글과 영문이 함께 나오는 자막은 **한글 줄만** 옮깁니다. 글자 인식은 확장 안에 들어 있는
  한국어 인식 모델(PaddleOCR PP-OCRv5)로 PC 안에서 하며, 따로 내려받는 것이 없습니다.
  자막 위치가 더 위에 있으면 "자막 위치"를 1/3 로 바꾸세요. 자막이 없는 구간은 비어 있습니다.
- 자동 인식 결과라 고유명사·전문용어 등 틀린 글자가 있을 수 있으니 한 번 훑어보고 고쳐 쓰세요.
- 영상 파일 화질은 유튜브 탭에서 재생되는 화질 그대로입니다. 진행 중 유튜브 탭의 톱니바퀴(설정)에서 화질을 올릴 수 있습니다.
- 받은 영상의 저작권은 영상 주인에게 있습니다. 개인 보관·업무 참고 용도로만 쓰고 다시 올리거나 배포하지 마세요.

## (참고) 파이썬으로 유튜브 자막 만들기 (`transcribe.bat`)

유튜브에 올라온 자막은 쓰지 않고, **영상 음성을 직접 받아써서** 한글 자막을 새로 만듭니다.
자막이 영상과 다르거나, 영어로만 있거나, 아예 없는 영상에 씁니다.

1. 파이썬 3.9 이상을 설치합니다. (설치할 때 "Add Python to PATH" 체크)
2. `urls.txt` 에 영상 URL을 한 줄에 하나씩 적습니다.
3. `transcribe.bat` 을 더블클릭합니다. 처음 한 번은 음성인식 모델(약 1.5GB)을 내려받느라 몇 분 더 걸립니다.
4. `subtitles` 폴더에 영상마다 두 파일이 생깁니다.
   - `.srt` — 시간 정보가 있는 자막 파일 (영상 플레이어·유튜브 스튜디오에 올릴 수 있음)
   - `.txt` — `00:00 스크립트 내용` 형식의 스크립트

- 그래픽카드가 없는 PC에서는 영상 길이와 비슷하거나 더 걸립니다. 빠르게 하려면 `transcribe.bat --model small`, 더 정확하게 하려면 `transcribe.bat --model large-v3` 로 실행합니다.
- 음성인식 결과라 고유명사·전문용어는 틀릴 수 있으니 한 번 훑어보고 고쳐 주세요.
