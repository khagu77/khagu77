# 온라인 이슈 보고서 작성 규칙

현대차 온라인 이슈 보고서(.pptx) 작성 기준입니다. 담당자가 정한 규칙이며, 확장프로그램(`report-extension`)이 이 규칙대로 동작합니다.
규칙을 바꾸면 이 문서와 코드(괄호 안 파일)를 함께 고칩니다.

## 하루 작업량
- 엑셀에서 `+` 표시된 게시물만 보고서에 넣는다.
- **삭제된 게시물은 보고서에 넣지 않는다** (요약표·상세 페이지 모두 제외). (`capture.js` DeletedPostError)
- 보통 하루 8~9건, 많을 때 12건 (2페이지 요약표 최소 8칸, 최대 12칸).
- **작성 개수 설정** (작성 전 화면에서): `전체` 체크 → + 글을 차례대로 전부(연번 1부터, 삭제 글은 빼고 이어서).
  체크 해제 → `총 N개 중 K개 작성` + `앞부분 작성 / 뒷부분 작성` 선택. N 은 엑셀을 넣으면 + 표시 개수로 자동 입력.
  - 뒷부분: + 글 중 **뒤에서 K개**를 (N−K+1)~N번으로 작성, 1~(N−K)번은 연번만 있는 빈 칸. 예) + 8개, 8개 중 4개 → 5·6·7·8번째 + 글을 5~8번으로.
  - 앞부분: + 글 중 **앞에서 K개**를 1~K번으로 작성, (K+1)~N번은 연번만 있는 빈 칸.
  - 나머지 + 글은 다른 담당자 몫이라 열지 않음. 번호는 + 글 순서 그대로(삭제 글 자리는 빈 칸). 상세 페이지도 그 번호(No.)로. (`app.js` countPlan, `pptx.js` 번호별 배치)

## 파일
- 파일 이름: `YYMMDD_현대차 온라인 이슈 보고서.pptx` (날짜만 매일 바뀜)
- 저장 위치: 담당자가 설정에서 고른 폴더(예: `현대차_2026_온라인모니터링/2026_오전 보고서/오전보고서_최종파일`)에 바로 저장. 같은 이름이 있으면 덮어쓰지 않고 '이름 (1)', '(2)' … 로 새로 저장 (시스템 작성본도 같은 번호). 고른 폴더가 없거나 저장 실패 시 다운로드 폴더. (`app.js` saveDir)
- 서식·폰트·안내선은 완성된 보고서(템플릿)를 그대로 따른다. (`pptx.js`)
- 2페이지 요약표: 칸 수(8·10·12개 …)와 상관없이 **표 아래 끝선은 템플릿 표와 같은 위치** — 표 틀 높이에서 머리글 행을 뺀 높이를 데이터 행에 똑같이 나눔. 복제한 행마다 PowerPoint 행 ID(a16:rowId)를 새로 매김(같으면 PowerPoint 에서 표 수정·크기 조절이 안 됨).

## 작업 화면

## RAW data 엑셀 (차종별 온라인 동향 raw data)
- 메뉴 **[RAW data 엑셀 파일 받기]**: 오늘 PPT 작성용 엑셀의 **모든 행**을 지난 RAW data 엑셀(`YYMMDD_차종별 온라인 동향 raw data.xlsx`) 끝에 이어 붙여, 보고서 날짜로 이름을 바꿔 저장 (`raw.js`)
- 시트 2개: **'현대자동차'** = 제네시스 차종을 뺀 모든 차종 / **'제네시스'** = 제네시스 차종만 (C열 차종 코드로 구분: RG3·RG4·RS4·JX·JK·JW·IK·DH·JG·HI·GV·G70·G80·G90)
- **A열 연번은 각 시트의 마지막 연번에서 이어서.** B 커뮤니티명 / C 차종 / D 게시일(오늘 엑셀의 게시일 그대로) / E 구분 / F 게시글 위치(하이퍼링크) / G 주요 내용
- 오늘 엑셀의 **'+' 표시는 넣지 않음**. 노랑·파랑 등 **셀 색은 모두 없앰**(시트 마지막 행과 같은 글꼴·테두리·날짜 형식)
- 저장할 때 **커서는 각 시트의 마지막 연번 바로 아래 A열 칸**(그 칸이 화면에 보이게)
- 만든 RAW 파일은 확장이 기억해 두었다가 **다음 날 그 파일에 이어 씀** (처음 한 번만 설정에서 지난 RAW 파일을 넣음). 같은 게시일 자료가 이미 있으면 두 번 넣는지 물어봄
- 저장 위치는 PPT 와 같은 저장 폴더
- Mac Finder '정보 가져오기'의 **'출처(chrome-extension://…)'** 표시는 크롬이 저장한 파일에 macOS 가 남기는 기록이라 확장에서 끌 수 없음 → README 의 지우는 방법 안내

| 불만 구분 | 대부분 **주의**. 악성 민원 또는 주요 심각한 이슈는 **경고**, 화재·급발진 등은 **심각**. 해당 단계 글자만 색: 주의 초록 `00B050` / 경고 파랑 `0563C1` / 심각 진한 빨강 `C00000` (`pptx.js` LEVEL_COLORS) |

| 댓글 반응 | 캡처한 댓글 2개를 **댓글 캡처에서 위에 놓인 댓글부터** 차례로 요약 (`ai.js` comment_picks 오름차순). 그대로 옮기지 않고 오탈자·맞춤법을 고쳐 자연스럽게. **댓글 말투를 따름**(존댓말이면 존댓말 — 말 그대로 여론). 각 문장 끝에 **마침표**, 느낌표·물음표 댓글이면 그 기호. **두 댓글 사이에 쉼표**. 형식: `‘…습니다., …하세요!’ 등의 여론` |

## 캡처
- **영운모(truckerking)·넥쏘카페는 글 주소로 바로 들어가지 않는다 → 네이버에서 글 제목을 검색해 검색 결과의 글 링크로 들어가야 열린다** (가입하지 않아도 검색 결과로 들어오면 보이는 카페). (`capture.js` SEARCH_ENTRY_CAFES, enterViaSearch)
  - 제목: 엑셀 '제목' 열 → 없으면 카페 전체글 목록에서 글번호로 찾음. 네이버 검색(카페 탭)에서 같은 카페주소·글번호 링크를 눌러 들어감.
  - 다른 동호회도 글 주소로 열었을 때 본문이 안 보이면(가입 필요) 같은 방법으로 다시 시도.
  - 게시글 위치 칸에는 검색 표시(?art=…)를 뺀 원래 주소 `https://cafe.naver.com/truckerking/글번호`.
- 모든 캡처는 고화질(화면 2배)로 찍고, 슬라이드에 놓이는 크기 기준 **150ppi(기본, PowerPoint 그림 압축 "화상(150ppi)" + 잘려진 그림 영역 삭제와 같음)** 로 줄인다. (2026-10-20 담당자 요청으로 330 → 150. 예전 저장값 330 도 한 번 150 으로 바꿈) 설정에서 220·150ppi 로 바꿀 수 있음. 크게 줄일 때는 절반씩 단계적으로 고품질 축소. 줄일 때는 **가로세로 비율 유지**(임의로 찌그러뜨리지 않음). 잘라낸 부분은 지움. (`imageproc.js` encodeAtPpi)
- **제목 캡처**: 게시판 이름 · 제목 · 작성자 동그라미 아이콘 · 닉네임 · 작성일·조회수(오른쪽 댓글·URL 복사 포함)를 **한 장**으로. 글 제목 영역(article_header)만 찍고, 글 아래 '○○님의 게시글 더보기' 영역은 섞지 않음. 아이콘이 잘리지 않게 줄 간격은 줄이지 않음. 가로 15cm(높으면 12cm).
- 연한 회색 **기본 프로필 아이콘**도 배경으로 보고 잘라내지 않는다 (`imageproc.js` INK_DIFF). 폭 대부분을 덮는 칸 구분선은 지운다.
- **본문 캡처**: **작성자가 쓴 본문만.** 카페 게시판 글쓰기 양식으로 본문 맨 위에 자동으로 들어가는 운영 안내(예: 아이오닉9 오너스 자유게시판의 "📍 함께하는 … 카페 / 질문은 질문 답변 게시판 … / 카페 활동 예의 … ____")는 캡처·요약에서 뺀다. 화면에 보이는 **줄 단위**로 판단(안내 문구와 본문이 한 글 상자·한 문단 안에서 줄바꿈으로만 이어져 있는 경우가 많음). 안내 줄의 글자만 가리고, 안내만 든 상자는 밑줄·테두리까지 통째로 가림. 아이오닉9 오너스 공통 문구는 미리 등록(`SEED_BOILERPLATES`, 띄어쓰기·이모지 무시하고 글자만 비교). 맨 앞부터 이어지는 '운영 안내 말(카페·게시판·등업·예의·회칙·탈퇴·작성해주세요 등)' 구간과 **빈 질문 양식**("1. 구동방식: 2. 인승: 3. 색상: …" 처럼 값이 비어 있는 항목)을 마지막 구분선(`____` 밑줄 문단·가로줄)까지 뺀다. 구분선이 없으면 맨 앞 안내 문단들만. 양식에 값을 채운 줄(예: "구동방식: AWD")은 작성자 정보라 남긴다. 한 번 찾은 문구는 기억해 다음 글에서도 뺀다 (`capture.js` boilerplate).
- 본문 첨부 이미지는 가리고 글자만. 빈 줄은 없애되 **줄 간격은 원래 글의 자연스러운 간격**(글자 높이의 약 절반)으로 — 너무 빡빡하게 붙이지 않음. 원본의 51%(넘치면 46%), 4.56cm 안내선부터.

## 제원 2.5 / 2.5T 구분 (2026-10-20 담당자 지정)
- 터보면 반드시 **T** (2.5T, 3.5T, 1.6T), 자연흡기(N/A) 모델이면 숫자만 (2.5, 2.0). "2.5 터보", "2.5t" 도 "2.5T" 로 통일.
- 그 차종에 그 배기량이 터보뿐이면 "2.5" 로만 적혀 있어도 T (아래 차종별 제원표 기준). (`app.js` SPEC_LINEUP, normSpec)
- 연료도 구분 (2026-10-20 담당자 지정): 같은 차종에도 LPI·디젤 모델이 있다. 디젤은 **"3.0D", "2.2D"** (배기량+D), LPI(LPG) 모델은 **배기량 없이 "LPI"** 만 (담당자 지정). 디젤은 **배기량 없이 쓰지 않는다**: 글에 배기량이 없으면 아래 제원표에서 그 차종의 디젤로 채움 (싼타페 TM 은 2.2D). "2.2 디젤", "디젤 2.2" 도 "2.2D" 로 통일. 하이브리드 HEV, 전기 EV, 수소 FCEV.
